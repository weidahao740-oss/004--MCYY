# Morrow Live2D 分层制作说明（简版）

用途：把 Morrow 核心图拆成 Live2D Cubism 可识别的分层 PSD，用于后续呼吸、眨眼、耳朵、尾巴和说话动作。

## 一、基本要求

- 画布：`2048 × 2048`，所有图层保持原位置，不移动、不缩放。
- 格式：PSD，图层名使用下文英文名。
- 背景：Morrow 单独透明背景；房间另存干净底图，不放进角色 PSD。
- 拆层方式：每个部件独立成层，只保留该部件，边缘干净。
- 遮挡补画：部件移动后会露出的位置要补完整，不能有空洞。
- 光效：发光月牙、尾巴光点单独成层，不画死在身体或尾巴上。

## 二、图层清单

建议图层结构：

```text
Morrow_Live2D.psd
├─ 左耳
├─ 右耳
├─ 左眼
├─ 右眼
├─ 左眼闭合
├─ 右眼闭合
├─ 嘴巴闭合
├─ 嘴巴张开
├─ 头部
├─ 身体
├─ 尾巴
├─ 额头月牙光
├─ 尾巴光点
└─ 脚下阴影
```

建议图层顺序（从上到下）：

```text
额头月牙光
左耳 / 右耳
左眼闭合 / 右眼闭合
左眼 / 右眼
嘴巴张开 / 嘴巴闭合
头部
尾巴光点
尾巴
身体
脚下阴影
```

## 三、各图层要求

| 图层 | 内容 | 注意事项 |
|---|---|---|
| 左耳 | 左耳、耳根、耳内绒毛 | 耳根多画一截藏进头毛，方便旋转 |
| 右耳 | 右耳、耳根、耳内绒毛 | 与左耳分开，不能合并 |
| 左眼 | 睁眼左眼、眼眶、虹膜、高光 | 眼外圈包一点同色毛，避免转动露白边 |
| 右眼 | 睁眼右眼、眼眶、虹膜、高光 | 与左眼对称，高光一致 |
| 左眼闭合 | 左眼闭合眼皮 | 只保留眼皮，其他区域透明 |
| 右眼闭合 | 右眼闭合眼皮 | 只保留眼皮，位置对准右眼 |
| 嘴巴闭合 | 默认闭嘴、鼻头、嘴缝 | 覆盖默认嘴部 |
| 嘴巴张开 | 张嘴、口腔、舌头 | 说话时显示，边缘用毛色包住 |
| 头部 | 脸、额头毛、脸颊毛、下巴毛 | 去掉耳、眼、嘴、月牙后的头部主体 |
| 身体 | 躯干、四肢、胸口绒毛 | 不含尾巴；脖子和胸口要补完整 |
| 尾巴 | 整条尾巴本体 | 不含光点；尾巴根多画一点藏进身体 |
| 额头月牙光 | 月牙及光晕 | 透明底发光，方便调亮度 |
| 尾巴光点 | 金色、青色光点和星点 | 透明底发光，方便闪烁和聚拢 |
| 脚下阴影 | 脚下柔边接触阴影 | 不带地面，透明底 |

## 四、重点补画区域

拆层时重点检查以下位置，移动部件后不能出现空洞：

1. 耳根后面的头毛；
2. 下巴和头转动后露出的脖子毛；
3. 尾巴根被身体挡住的部分；
4. 眼睛转动时眼眶周围的毛色；
5. 嘴巴张合时嘴周围的脸部毛色。

## 五、命名注意

- 眨眼层必须命名为：`左眼闭合`、`右眼闭合`，方便 Live2D 自动识别眨眼。
- 不要使用 `闭眼L`、`eye_close` 等其他名字。
- 左右部件必须拆开，不要把双耳、双眼合并成一层。

## 六、制作顺序建议

1. 复制原图，保留一层完整原图作为保底层；
2. 抠出透明背景 Morrow；
3. 拆身体、尾巴、头部等大部件；
4. 拆左右耳；
5. 拆左右眼和闭合眼皮；
6. 拆闭合嘴和张开嘴；
7. 拆额头月牙光和尾巴光点；
8. 单独导出脚下阴影；
9. 补齐所有被遮挡区域；
10. 按本说明命名图层并保存 PSD。

## 七、交付检查

- PSD 尺寸为 `2048 × 2048`；
- 图层名称和清单一致；
- 闭眼层、张嘴层、光效层可以单独开关；
- 关闭闭眼、张嘴、光效层后，Morrow 仍然完整；
- 轻微移动耳朵、头部、尾巴时没有空洞；
- 背景透明，房间底图单独保存。
