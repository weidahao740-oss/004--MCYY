## 维护规则

1. 本目录为任务档案体系，唯一状态源仍为根目录主计划。
2. 状态词仅允许：completed / partial / reopened / superseded / blocked / not-started / in-progress。
3. 技术能力与任务整体状态分开记账；技术实现存在 ≠ 整项任务 completed。
4. 剧情无关冻结层（UI/按钮交互/通用教学状态机）= completed 技术能力，不等同整体验收 completed。
5. 内容层（按钮文字/台词/目标句/教学内容/语音）为可替换层，随剧情审定更新。
6. 旧 `项目计划/` 目录文件一律保留不删不改；新口径以本看板与主计划为准。
7. `PROJECT_BASELINE.md` 承担长期稳定规则，不在本看板重复其职责。
