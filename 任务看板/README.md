## 维护规则

1. 本目录为任务档案体系；当前状态以根目录[项目状态快照](../项目状态快照.md)为准。
2. 状态词仅允许：completed / partial / reopened / superseded / blocked / not-started / in-progress。
3. 技术能力与任务整体状态分开记账；技术实现存在 ≠ 整项任务 completed。
4. 剧情无关冻结层已确认 ≠ 内容冻结或整体验收 completed。
5. 内容层随剧情审定更新；按章校准、验收、冻结，不以未完成章节阻塞已满足门槛的章节。
6. 旧 `项目计划/` 目录一律保留并作为历史资料；现行口径以本看板与主计划为准。
7. `PROJECT_BASELINE.md` 承担长期稳定规则，不在本看板重复其职责。
8. 正式事件正文采用“一章一份正式内容文件”：第一章唯一来源为 `CHAPTER_01_BIRTH_CONTENT.md`，第二章唯一来源为 `CHAPTER_02_CHILDHOOD_CONTENT.md`；任务卡只记录状态、依赖、验收与证据，不重复保存完整正文，也不为单个事件另建独立重写稿。
