### 首次产品表达教学顺序

共同开头为 `Hello? Is someone there?` → 自然中文情境理解 → 中文意图选择；中文选择只决定路线，不产生英语证据。

- `Yes, I’m here.`：听完整句和中文意思 → `Yes`、`I’m here` 分别真实跟读 → 点击式语块排序（仅两个已学语块，固定反向 `I’m here` / `Yes,`，可从上方撤回重排）→ 播完整句 → 完整句真实录音。
- `Hi. I can hear you.`：听完整句和中文意思 → `Hi`、`I can hear you` 分别真实跟读 → 点击式语块排序（固定反向 `I can hear you` / `Hi.`；不拆成孤立单词）→ 播完整句 → 完整句真实录音。
- `Who are you?`：听完整句和中文意思 → `Who` 真实跟读 → `Who are you?` 完整表达真实跟读 → 听音选情境图确认理解（询问陌生对象身份 vs 告诉对方自己在这里；不使用未选路线英文作干扰）→ 完整句真实录音。
- 三路均以真实录音 → ASR 确定性唯一匹配 → 识别结果展示 → 用户确认 → Morrow 分支反馈 → 共同收束结束；共同收束完成后才写入 `first_response_style`。排序首次错误提示再听哪句先说，连续错误才给自然中文顺序提示；无跳过。

- 这是新用户首次进入产品后的第一条真实英文表达，仅此一次走完整保底教学。
- 只给所选路线记录学习证据；未选路线不因同屏出现而产生学习证据。
- 必修跟读和完整句真实表达都必须真实录音并识别通过；不能用点击、文字或其他界面动作代替。
- 所有剧情事件中的必需教学都不允许用户跳过，任何界面都不提供“跳过”按钮。E01-01 作为唯一一次首次产品表达完整保底，不依据既有学习证据裁剪；此后事件由系统依据既有学习证据自动不呈现不需要的步骤，属于证据裁剪，不属于跳过。
- `稍后继续`只保存临时意图与教学进度，不结算事件、不触发正式分支反馈、不写 `first_response_style`。
- 麦克风、网络或 ASR 异常时只能重试或稍后继续，不得绕过必修步骤。
