## 已被替代的主要路线

- Web/PWA 曾作为早期原型目标；现已改为仅作开发测试端，正式目标是微信小程序和 App。
- 早期生成式 LLM 对话链路与角色提示词曾作为 MVP 主链路；现已改为固定内容、确定性意图和规则引擎，LLM 默认关闭。
- 早期多供应商实时 TTS 比较仅保留作历史资料；现行方案是离线生成审核通过的预制语音，运行时不实时合成。
- 第一轮 Morrow 样音使用 `qwen-audio-3.0-tts-flash` + `loongjohn`，开发者试听后认为整体偏老气；第二轮使用 `qwen-audio-3.1-tts-flash` + `Luna_v3.1`，仍未作为正式方案。随后两轮 Morrow TTS 样音、清单和探测文件均被删除，产品改为幼年、少年、成年三阶段成长音色。
- 开发内存存储仅用于旧 Web 原型；正式持久化目标是 PostgreSQL。
