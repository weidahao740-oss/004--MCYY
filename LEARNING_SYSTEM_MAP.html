Morrow 语言学习系统结构图

依据《MORROW_LANGUAGE_CURRICULUM.md》v1.0.0 ｜ 三条线同图：纵向七章成长时间线 · 横向用户难度三档（与章轨平行、不改写）· 单条六阶掌握闭环（含遗忘回退与间隔复现）｜ 全图离线可读，无外部资源

一、纵向：Morrow 七章成长时间线（章轨，单调递增）

本轨道决定 Morrow 自己"能说多复杂的英文"。由 Morrow 的人生阶段决定，任何用户难度档都不能把某一章的台词改难或改易。第 1、2 章为已写台词收敛，第 3—7 章为规划目标。
第1章出生与苏醒chapter_01_birth
本章语言上限：极短句（I am… / This is… / I see…），平均句长 ≤ 8 词、最长 ≤ 16 词；禁过去时连续叙事、禁比较、禁从句链。
第2章童年探索chapter_02_childhood
本章语言上限：This is where… / I like… / It sounds like… / 首次 small…than，平均 ≤ 9 词、最长 ≤ 18 词；允许 1 个短定语从句与一次空间比较。
第3章第一次上学chapter_03_first_school（规划目标）
本章语言上限：Could you…? / I don't understand. / When/if 短状语从句，平均 ≤ 11 词、最长 ≤ 22 词；首次礼貌求助，禁虚拟语气。
第4章校园成长chapter_04_school_growth（规划目标）
本章语言上限：because/so 因果 + who/which 短定语从句，平均 ≤ 12 词、最长 ≤ 25 词；友谊、合作、冲突—和解用语，禁双从句嵌套。
第5章毕业与选择chapter_05_graduation（规划目标）
本章语言上限：A 与 B 比较 + If I…, I'll… 第一条件句 + 两步计划，平均 ≤ 13 词、最长 ≤ 28 词；禁第三条件句、禁工作日常词。
第6章初入社会chapter_06_first_work（规划目标）
本章语言上限：I was wondering if… / 工作事件回溯 / 转述，平均 ≤ 14 词、最长 ≤ 30 词；会安排时间、澄清误会，禁人生哲学长段。
第7章独立生活chapter_07_independent_life（规划目标）
本章语言上限：全时态开放 + 一次性 If I had…, I would have… 第三条件句做回顾，平均 ≤ 15 词、最长 ≤ 32 词；仍限平均句长，不堆复合从句。

二、横向：用户难度三档（与章轨平行的独立轨道）

这三档只调整用户这一侧的任务脚手架。同一场景 × 不同难度档 = 不同任务提示与参考句长度，但同一章节、同一剧情、同一句 Morrow 台词。
同一章（例如第 3 章"第一次上学"的同一事件"举手求助"）下：
basic 基础

完整骨架 + 提示多

用户得到完整可填参考句（含提示词），允许多次提示（prompted 阶段宽松）。Morrow 台词不变。

intermediate 中等

半句骨架 + 1 个替换词

用户得到半句骨架与 1 个替换词提示；提示退出后进入 independent。Morrow 台词不变。

advanced 进阶

无骨架，只给中文意图

用户只看到中文意图与 1 个示范；被期望一次产出更长的英文回句。Morrow 台词不变。

双轨独立红线：无论用户选 basic / intermediate / advanced，Morrow 在本章说的词库、句长、时态、从句上限都由"一、纵向七章时间线"决定。难度档永不改写章轨上限，也不改变剧情走向；它只改用户被要求产出的英文复杂度。

三、闭环：六阶掌握状态循环（每个词目 / 句型一条）

掌握六阶与"章轨""难度档"正交：同一个句型在第 3 章被 encountered，到第 4 章新场景里 transferring，到第 5 章 mastered；长期未复现则沿灰色虚线遗忘回退，再由间隔复现机制带回新场景重新 encountered。
正常递进（六阶前进） 提示退出路径（prompted → independent） 间隔复现回到新场景（mastered → 新场景 encountered） 遗忘回退（长期未复现，退回 encountered）
三条线如何协作：① 纵向章轨决定 Morrow 七章自己能说多复杂的英文；② 横向难度三档只决定用户这一侧的参考句脚手架，不改 Morrow 台词、不改剧情；③ 六阶闭环挂在每一个词目/句型上，与前两轨正交，控制"什么时候算会了、忘了怎么回来、怎么到新场景再用"。术语与 `MORROW_LANGUAGE_CURRICULUM.md` 一致：掌握六阶 encountered / recognized / prompted / independent / transferring / mastered；难度档 basic / intermediate / advanced。
