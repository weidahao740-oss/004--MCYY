## 启动方式

新版原型读取现有后台进度，需要同时打开后台和原型。已经启动的旧版本服务需要重新启动才能使用本轮接口。

在一个终端进入 `C:\004-MCYY\english-pet`，按项目原有方式启动 API：

```powershell
cd C:\004-MCYY\english-pet
npm run workspace:materialize
npm run dev:api
```

在另一个终端启动原型：

```powershell
cd C:\004-MCYY\morrow-ui-prototype
npm run dev
```

打开原型终端显示的网址。原型会把后台请求转到本机 8787 端口；实际端口被改过时需同步调整 `vite.config.ts` 的转发地址。已有依赖按项目当前环境使用，本轮没有执行安装或启动命令。

## 语音后置是什么意思

墨洛的正式配音和跟读示范这轮没有制作。没有声音时可以先读英文、展开中文，体验页面与操作；听力和播放节奏以后再确认。

用户自己的录音与识别仍然保留。请沿用后台已经配置的真实 ASR；如果服务使用模拟识别，新原型会明确提示“真实语音识别还没有接通”，停在当前步骤，不会假装完成。不要把识别服务的密钥填到原型前端。

## 可以怎样体验

先进入第一章，选择一种中文回应，只学习自己选的路线。单词／语块跟读后，会展示识别结果，需本人确认；不对就重录。最后再完整说出想对墨洛说的话。

可以在中途点“稍后继续”，重新进入后接着服务端最近确认的步骤。排序中尚未确认的点选和未确认录音不会当作已完成。

点击“稍后继续”后会先收起录音入口，等待后台确认暂停；若请求失败，会提示重试，不会声称已经暂停。再次点“继续刚才”时先读取后台最新位置。暂停成功后即使房间安排暂时没读到，也会先离开录音页。

申请麦克风权限和录音期间不能重播墨洛的声音，结束采集后恢复播放入口。尚未确认时切后台会取消录音或丢弃转写；已经点了确认后切后台，则继续等待该次提交，不同时发送作废请求。

识别内容没有通过时会回到重录；如果只是网络超时，可以重试同一次确认，也可以回房间重新读取进度。点“不是，重新录”或暂停后，原录音结果不会继续用来推进剧情。

房间、成长、共同经历、设置都读取同一会话的实际进度。回访由后台自然安排，没有回访题库入口；每日新增数量沿用后台限制，不能靠原型按钮绕过。

原型保存独立游客会话，旧原型本地完成记录不会导入，正式 Web 的账号进度也不会自动合并。请保留当前浏览器的站点数据；会话失效时原型不会静默创建新账号掩盖旧进度。
