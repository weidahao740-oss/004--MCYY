## 本轮代码实现与边界

2026-10-16 已写入以下实现，均不代表运行通过或用户体验验收：

- `morrow-ui-prototype/src/pages/HomePage/HomePage.tsx` 改接服务端现行第一章内容、推荐、事件结算、暂停与继续；沿用房间、玻璃气泡和底部导航。普通流程移除旧恢复物品剧情、场景教学热点、全局难度、跳过跟读及结果预览。四类场景仍复用现有房间底图。
- 新增 `backend.ts`、`SpeechInput.tsx`、`StoryLine.tsx`、`s09.css`。真实麦克风录音交现有服务端 ASR，先展示只读转写再由用户确认；取消、离页、切后台时释放麦克风并取消未完成请求。界面不提供手改转写通过。未收到响应的操作沿用原编号，避免重试重复结算。
- `vite.config.ts` 保留原输出插件，开发态把 `/v1` 与 `/tts` 转发至本机 8787 API；部署时使用 `VITE_API_BASE_URL` 或同源转发。原型不再是能靠本地假进度走完的离线演示。
- API 新增 `POST /v1/fixed-content/events/:instanceId/teaching`，按当前实例、状态与教学步保存检查点。教学跟读凭证和最后完整表达凭证分开，不能复用。启用教学的实例，在当前必需教学完成前不能推进真实表达。
- 教学数据存入现有用户事件 JSON，账号清除时随原事件数据清除；不新增数据库表，不导入旧原型 localStorage 的学习证据。只使用该用户真实 ASR 转写并确认过的对象裁剪重复成分。
- E01-01 只教所选路线，两个必需跟读后做对应排序／身份理解图，再做完整句录音；首次保底不按历史证据裁剪。身份图仅为缺音频时的文字／画面理解，不记听力识别通过。
- E01-02 使用 `I noticed`、所选物品语块、`first` 的实际证据；至多一次 `first / too / again` 填空。观察反馈放在教学与搭建之间；服务端对已呈现反馈作去重。第二表达保持完整语块，用户确认 `What about you?` 后才显示墨洛回答，末尾结算 `first_shared_object`。
- E01-03 以 `I'll` + `call you Morrow` 编排。其他第一章表达按正文的自然语块、必要排序和完整短语配置；E01-11 只回采原路线的一句旧表达，不创建新学习对象或理解／搭建题。调度与每日预算继续由原引擎决定，原型不另写调度。
- 第一章录音输入只接受当前路线固定目标及标点／标准缩写的等价形式，保留否定，不作开放语义猜测。Mock ASR 不签发事件凭证，原型也不把模拟结果当作成功。
- 原型证据暂保守记 `prompted`，不自动生成 `independent`／`mastered`。完整掌握阶位与正式学习证据展示仍需在 S10 迁移中对接；不把服务端教学检查点冒充长期掌握。
- 角色播放器只接受 ID 与版本相符的 ready 文件，planned 显示文字提示；单页互斥播放、录音前停播、离页停播。没有调用 TTS 或浏览器系统朗读。

语音后置项：示范听读、慢速示范、听音理解、声音质量与播放节奏均待后续音频补齐。当前“先看文字再录音”仅供非音频体验确认，不能宣称完整听力教学已经完成。19 条 Morrow WAV 队列不因本轮改变；用户跟读示范的接口与素材范围在 S10／S07 对接时继续单列，不能冒用角色音频。

原型首次连接创建独立游客会话，原型与正式 Web 的账号进度不会自动合并；原型会话失效时显示错误，不自动换新账号掩盖进度。部署域名与正式账号衔接留在 S10。

## 更新前的源码情况与本轮要求

### 2026-10-17 继续实现

本轮继续完成以下代码修改，仍未启动服务、运行测试或做效果检查：

- 修正第一章录音唯一匹配表达式中多出的括号，避免接口源码解析失败。
- 区分“后台已处理但当前表达没通过”和“没有完整收到后台结果”：前者清除已消费的转写，直接给出重录入口；后者保留本次转写及操作编号，可以重试确认，避免重复推进。
- 普通接口增加 30 秒超时，录音识别增加 90 秒超时；重复发起同一操作时复用正在等待的请求。超时不声称事件一定未推进，允许回房间读取实际进度。
- 新增录音凭证取消接口。否认转写、切后台和离页时，原型立即丢弃转写，并尝试通知服务端作废；断网时仍有新录音替换、暂停作废和有效期限制。取消接口不结算剧情、不写学习完成证据。
- 服务端暂停时统一作废该实例尚未使用的录音凭证；尚未完成当前必需教学时，不签发最后完整表达的凭证。重录时顺带清除过期凭证。
- 教学检查点同步关注中文译文及版本变化；读取已有教学进度不再反复保存无用的操作回执。
- E01-02 进入中文态度选择时，不重播“你第一眼注意到了什么”的旧提问；直接承接刚读完的墨洛回答。
- 录音增加最终文件大小判断、无效到期时间处理和麦克风中断提示。
- 暂停请求等待期间立即卸下录音入口；暂停成功后先切到目标页面，再刷新房间安排，避免刷新失败把用户留在旧录音页。暂停请求失败时仍保留当前页面，不声称已经暂停。
- “继续刚才”先读取后台当前实例，再决定是否恢复；已结束或已变化的进度按后台返回处理，不直接复用页面中保存的旧步骤。
- 从申请麦克风权限到结束采集期间，共用录音占用状态禁止角色声音重播；取消、异常或离页时释放占用，旧组件不能解除新组件的占用。
- 用户已点击确认时，切后台或组件卸载不再同时发送凭证作废请求；麦克风资源仍会释放，确认结果继续由后台处理。

本轮未改变正式语音后置安排，未将 S09 标为完成，未启动 S10 正式迁移。

## 非音频黄金路径

1. 点击“去看看是谁” → 章节开场演绎 → E01-01。略过演绎不略过事件或教学。
2. E01-01 开场 → 中文意图选择 → 只学习所选路线 → 必需真实录音／ASR／确认 → 专属反馈 → 共同收束 → 正式结算 `first_response_style`。
3. E01-02 共同观察 → 中文物品选择 → 所选语块教学 → 墨洛等义反馈 → 必要填空与第一表达真实录音确认 → 墨洛过渡 → 第二次真实表达 `What about you?` → 墨洛自己的观察回答 → 中文态度与收束 → 正式结算 `first_shared_object`。
4. 后续事件只由公共调度推荐；主线主推荐，回访每次最多一条非抢占提示，不做回访页面或目录入口。
5. 暂停、拒绝转写、识别异常时留在当前检查点；只允许重试／重录／稍后继续，不进入正式结果。
6. E01-12 满足所有主线及必要世界状态后才结算第一章。日常数量、回访、长期记忆保存和掌握等级不作为硬门。
