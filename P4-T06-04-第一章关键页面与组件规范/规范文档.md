## 2. P1–P10 页面规范

### P1 初次进入页
- 全屏暗房间（plain 渐变），呼吸金光点，中文引导「房间里有一个微弱的声音。」
- 主操作「听听看」、次操作「先看文字」、辅助「暂时离开」；底部小字「可以先体验，需要跨设备保存时再绑定账号」。
- 不出现：注册表单、问卷、水平测试、多宠物选择、付费、底部导航。
- 状态：正常（呼吸光）、加载（轮廓淡入）。

### P2 初次相遇流程（连续 7 步，不切页）
- 无底部导航、无事件目录、无进度条。
- 关键帧：苏醒第一句 `Hello? I can hear someone beyond the room.` → 自我介绍 `I'm Morrow. What should we do first?`（称呼可选）→ 第一次自由表达 → 三件模糊轮廓（灯/植物/铃铛，带微光热区）→ 物品清晰 → 自动记忆 → 回 P3。
- 台词条统一：英文 + 重听 + 语速 1.0×/0.8×/0.6× + 查看中文（默认收起）。

### P3 陪伴首页（至少两种动态生活状态）
同一底图，只切 UI 层。画廊覆盖 6 态：
1. **主动邀请态**：左上状态胶囊「正在听窗边的声音」；右上英文气泡 `I hear something near the window.`，尾巴指向 Morrow；主邀请「和我一起听听」+ 次「稍后再说」；底部三栏导航。
2. **首次探索引导态**：无台词气泡、无邀请按钮；底部一次性无尾巴中文提示「可以点点 Morrow 或房间里的东西试试看。」冷蓝灰，操作后淡出。
3. **普通自由陪伴态**：无台词、无邀请；居中主入口「和 Morrow 说话」打开 P5。
4. **安静陪伴态**：长按 Morrow 0.8 秒进入；环境声降 30%，一句 `We can stay quiet.`，不伪装学习证据。
5. **加载态**：Morrow 待机呼吸光点。
6. **离线态**：冷蓝警告横幅「连接暂时中断，房间与 Morrow 还在。文字草稿会留在本地。」

互斥规则：主动台词气泡、首次探索提示、逐级帮助同一时刻最多一种。

### P4 情境互动页（共用 S0–S8 状态机）
- 隐藏底部导航；无通用返回箭头；右上（或顶部安全区适当位置）仅「暂停」文字动作（透明命中区 ≥44）；场景区 + Morrow 回应区 + 底部输入区。
- 画廊覆盖 7 态：
  - S2 邀请表达（台词 + 输入上拉 + 帮助入口）
  - S5 听懂行动（`Near the window. Let's go.` + 金色「Morrow 正按你的意思走过去」）
  - S4b 歧义（复述一个可能意思 + 一个澄清问，原输入保留可编辑）
  - S4c 没听懂（`I hear the words, but not the meaning.` + 提示重说/打字/帮你一下）
  - S4d 候选意思（连续两次无匹配 → 最多 3 个中文候选卡，选它推进）
  - 暂停（`We can leave the room quiet for now.` + 回房间/继续刚才）
  - 加载（场景淡入）

### P5 快速表达 / 录音 / ASR 确认层
- 底部上拉层，不是聊天页；含 grip、输入框、麦克风、发送、「查看简单表达」折叠。
- 画廊覆盖 6 态：
  - 正常文字输入
  - 按住录音（声波动画）
  - ASR 待确认（转写高亮，可改后发送）
  - 低置信（黄边框 + 「我不确定是否听对了，请先检查」）
  - 麦克风拒绝（红色横幅「麦克风权限未开启。你可以打字继续。」，麦克风置灰但不重复强求）
  - ASR 无结果（黄横幅「没有识别到清楚的语音」，不创建消息/记忆）

### P6 逐级帮助层（场景区内折叠，不上拉整层）
四级，画廊各占一屏：
1. L1 关键词：`sound / window / bell / listen` 胶囊
2. L2 句型骨架：`I hear ___.` / `The sound is ___.` / `Let's ___ again.`
3. L3 可编辑参考句：`I hear a soft sound by the window.` / `Let's listen again.`
4. L4 候选意思：≤3 个中文意图卡 + 选它推进

任一层可收起、改文字/语音、切慢速、查看中文，不扣关系值。

### P7 互动结束层
- 底部上拉总结：Morrow 结束回应（中文）→ 房间/动作/关系变化 → 用户成功英文一句 → 一条更自然表达（绿字，仅确有价值时）→「回到房间」/「再听一次」。
- 不出现分数、正确率、错误列表、未来预告。

### P8 成长页
- 只展示已发生事实卡片：「Morrow 第一次走近了窗边」「房间里恢复了一盏灯」「Morrow 说话更完整了」。
- 禁止：进度条、百分比、下一阶段、还差多少。
- 状态：正常 / 空（新用户「还没有成长变化」）/ 加载 / 失败+重试。

### P9 词语回声页
- 三标签：最近遇见 / 还想再用 / 已经很熟；词条卡显示英文 + 当时场景中文。
- 禁止：未学内容、正确率、待办。
- 状态：正常 / 空 / 加载 / 失败+重试（缓存可读）。

### P10 设置与隐私
- 四组：体验（语速、字幕、中文译文、默认输入、声音）/ 记忆与数据（自动记非敏感互动、原始录音用完即删、清空全部数据）/ 账号与设备 / 关于 Morrow（隐私协议、反馈）。
- 本页不触发 Morrow 互动，不展示成长进度。

## 4. Web / 小程序 / App 共用与替换边界

### 4.1 三层共用（不改业务）
- 状态模型（L1 长期成长 / L2 当前生活 / L3 情境 / L4 即时反应）

### 4.2 平台适配层只处理
| 能力 | Web | 小程序 | App |
|---|---|---|---|
| 安全区 | `env(safe-area-inset-*)` | 胶囊按钮位 + 底部 tab 安全区 | 系统刘海/Home Indicator |

| 登录 | 访客/手机号 | 微信一键 | 微信/Apple/手机号 |

### 4.3 替换边界（不能跨平台硬搬）
- 微信小程序录音生命周期、后台播放、分享能力受限，需在适配层降级。

- 母版比例变化时重算留白与组件位置，不机械裁切；Morrow 始终是视觉焦点。
