## 4. 普通自由陪伴态

- 左上显示当前生活状态“正在安静陪伴”。

- 用户仍可直接触摸 Morrow、信封、铃铛和其他房间热区；快速表达与触摸并列为主要自然互动入口。
- 右上保留设置入口，底部沿用暗色整块三栏导航。

## 5. 共同视觉规则

- 同一底图、同一 Morrow、同一房间、同一道具位置。
- 主动对话气泡、首次探索提示和逐级帮助同一时刻只能出现一种。
- 底部“陪伴”为暖金色常驻激活态；“成长”和“词语回声”为低亮灰蓝。导航、选项卡、模式选择等具有明确“当前选中”语义的控件，点击后暖金状态常驻，直到切换到其他选项。
- 普通行动按钮默认使用淡蓝透明磨砂和冷白描边；按住／按下时短暂变为暖金反馈，动作完成或手指释放后恢复默认态。
- 状态胶囊使用确认稿中的左暖金低透明向右冷蓝灰过渡的磨砂渐变，不等同于按钮选中态。
- UI 使用冷蓝半透明磨砂玻璃层、细亮边框、暗色整块底部导航和暖金强调色。
- 不展示任务列表、金币、经验、饥饿值、成长进度或聊天消息列表。

## 6. 方向级视觉参数

以下参数以当前 1536×2752 设计母版为基准，用于锁定视觉比例和工程换算关系，不要求其他设备直接使用相同像素；P4-T06-04 再将其转换为组件 token、响应式尺寸和平台安全区。

### 6.1 画布、层级与安全区

| 项目 | 母版参数 | 方向规则 |
|---|---:|---|
| 设计母版 | 1536×2752 px | 竖屏手机构图，宽高比约 9:16 |
| 内容水平安全边距 | 约 62 px | 约占画布宽度 4%；窄屏不得小于系统安全区 |
| 手机状态栏 | 顶部约 0—135 px | 只承载系统时间、信号和电量，不放业务控件 |
| 状态胶囊 | x=62，y=180，450×123，圆角 61 | 左上固定；文字变化时不改变组件尺寸 |
| 设置入口 | 右上约 112×120 | 有效触控区不小于 44×44 CSS px |
| 底部导航 | y=2448，高约 304 | 三等分；固定在底部安全区之上 |
| 主要操作区 | 导航上方约 2100—2420 | 不遮挡信封、铃铛、Morrow 与主要触摸热区 |

### 6.2 颜色与材质

| 名称 | 建议值／范围 | 用途 |
|---|---|---|
| 暖金强调 | `#F2D389` | 只用于用户按下／点击后的短时反馈，释放后恢复淡蓝透明磨砂；不得作为按钮、卡片、导航激活项的默认常驻颜色 |
| 冷白正文 | `#F5F7FA` | 状态文字、系统状态栏、深色背景上的主要文字 |
| 低亮灰蓝 | `#C8D7E0` 附近 | 未激活导航、次级说明与低强调信息 |
| 深蓝黑导航 | `#081B28`，约 90% 不透明 | 底部整块导航背景 |
| 冷蓝灰浮层 | `#374E62`—`#718DA3`，约 30%—55% 不透明 | 次按钮、探索提示和冷色磨砂层 |
| 暖金渐变浮层 | 暖金低透明 → 冷蓝灰低透明 | 状态胶囊、主按钮；只用于当前重点或激活反馈 |
| 英文台词浮层 | 浅冷蓝灰，约 75%—85% 不透明 | Morrow 英文台词气泡，保证英文可读但仍露出房间 |
| 细亮描边 | 冷白／暖金，3—5 母版 px | 浮层轮廓；避免厚重手游按钮感 |

材质统一使用“淡蓝透明磨砂玻璃 + 冷白细描边 + 极轻内高光”。普通瞬时按钮默认复用确认稿中的淡蓝透明磨砂效果，按住／按下时短暂变为暖金，释放后恢复；导航激活项、开关已选中、标签页已选中等可持续选中状态常驻暖金，直至切换。默认不使用投射到大面积场景上的黑色重阴影；需要层级时优先增加透明度差、细边框或局部柔光。

### 6.3 字体与字号层级

| 文字角色 | 母版字号 | 字重 | 字体方向 |
|---|---:|---|---|
| 英文台词 | 约 58 px | Bold | Arial／系统无衬线，英文优先保证易读 |
| 状态胶囊 | 约 38 px | Bold | Microsoft YaHei UI／系统中文无衬线 |
| 主操作按钮 | 约 43 px | Bold | 系统中文无衬线，文案居中 |
| 导航标签 | 约 43 px | Bold | 激活项暖金，未激活项低亮灰蓝 |
| 探索提示 | 约 36 px | Regular | 冷白文字，默认冷蓝灰低强调 |
| “重听／查看中文” | 约 35—36 px | Regular | 深色文字置于浅色气泡内部 |

工程实现使用系统字体栈：中文优先 `Microsoft YaHei UI`／`PingFang SC`／系统无衬线，英文优先 `Arial`／`Inter`／系统无衬线。不得使用幼儿手写体、卡通描边字或高装饰字体。

### 6.4 圆角、描边和间距

- 状态胶囊和普通按钮采用接近半高的全圆角；台词气泡采用约 78 母版 px 的大圆角。
- 相邻双按钮之间保留约 150 母版 px 空隙；普通自由陪伴态单按钮水平居中。
- 按钮文字与描边之间必须有充足留白；中文长文案优先横向扩展，不压缩字体。
- 探索提示框默认约 1120×110 母版 px，水平居中；默认冷蓝灰，只有点击／触摸反馈才变为暖金强调。
- Morrow 台词气泡尾巴与气泡本体使用同一材质，根部无分隔线；尾巴只指向 Morrow，不指向用户或房间物品。
- 所有可点击控件在工程中最小触控区为 44×44 CSS px；视觉图标可以更小，但命中区不能缩小。

## 7. 三种首页状态的布局复用

| 状态 | 状态胶囊 | 中上区域 | 底部操作区 | 导航 |
|---|---|---|---|---|
| 主动邀请态 | 当前生活状态 | 英文气泡、重听、查看中文 | 主要邀请 + 稍后再说 | 显示 |
| 首次探索态 | 当前生活状态 | 不显示台词 | 一次性冷蓝灰探索提示，操作后淡出 | 显示 |
| 普通自由陪伴态 | 当前生活状态 | 保持房间与 Morrow 完整可见 | 居中的“和 Morrow 说话” | 显示 |

三种状态只切换 UI 层，不复制或修改房间底图。普通自由陪伴态证明首页在无主动事件时仍成立；主动邀请态证明情境入口成立；首次探索态只承担一次性触摸教学。

## 8. 动效、反馈与收起规则

### 8.1 UI 出现与收起

| 元素 | 出现方式 | 停留与收起 | 可打断／低运动版 |
|---|---|---|---|
| 状态胶囊 | 180—240ms 淡入，不做弹跳 | 状态切换时 150ms 交叉淡变 | `reduced motion` 直接替换文字 |
| 主动台词气泡 | Morrow 动作开始后 180—260ms 淡入并轻微上移 8—12 px | 语音结束后保留；用户无回应约 6—8 秒后收成一行轻提示；进入情境、选择稍后或开始其他操作时淡出 | 可被触摸、输入、录音立即打断；低运动版只淡入淡出 |
| 探索提示 | 进入无主动台词状态后约 4—8 秒且用户仍未操作时淡入 | 首次触摸、输入、说话或进入情境后 150—220ms 淡出；成功学会后永久不再显示文字 | 低运动版直接显示／隐藏，不做位移 |
| 探索提示点击反馈 | 默认冷蓝灰；按下时 80—120ms 变暖金 | 释放后 160—240ms 回到冷蓝灰，随后按操作结果淡出 | 不只靠颜色，按下时同时轻微亮边或缩放至 0.98 |
| 主／次按钮 | 120—180ms 淡入 | 点击后立即进入对应状态并禁用重复点击 | 低运动版取消缩放，只改亮度和禁用态 |
| 底部导航 | 页面进入时保持稳定，不随状态反复动画 | 切页时激活色 120—180ms 过渡 | 低运动版直接切换颜色与下划线 |

### 8.2 防打扰与优先级

1. 用户主动触摸、输入或录音的优先级最高；正在操作时不得出现新气泡、新探索提示或逐级帮助。
2. 主动台词气泡、首次探索提示、逐级帮助三者互斥，同一时刻最多显示一种。
3. 主动邀请被选择“稍后再说”后，本次打开不换文案重复邀请同一件事。
4. 长期未返回也一次只显示一个安静欢迎或一个轻量邀请，不补发多条内容。
5. 关闭声音后，台词字幕、查看中文、声音波纹或中文声音描述仍须完整可用。

### 8.3 Morrow 与场景动效

首页沿用《第一章功能界面与交互逻辑规格》的 12 项动效参数：待机呼吸 3.6—4.4 秒低频循环；看向用户 0.35—0.55 秒；看向物品／声源 0.45—0.7 秒；耳朵倾听 1.2—2.0 秒且最多循环两次；尾巴微光 0.8—1.4 秒。所有动效可被触摸、输入或状态切换打断，并提供 `reduced motion` 简化版。

## 9. 素材拆分与工程边界

### 9.1 必须独立拆分的 UI 素材／组件

- 状态胶囊：背景、描边和文字独立；文字由状态配置注入。
- 英文台词气泡：气泡本体、融合尾巴、英文文本、播放入口、查看中文入口独立。
- 主要按钮与次按钮：背景、描边、文字和交互态由组件实现，不压进底图。
- 探索提示：冷蓝灰默认态、暖金按下态、文字独立；不包含气泡尾巴。
- 设置入口、播放图标、麦克风图标、导航图标／文字和激活下划线独立。
- 底部导航：背景与三栏项目独立，激活项由当前页面状态控制。
- 触摸热区提示：耳朵／眼神动作、物品微光、波纹、声音碎片作为独立动效层，不写死在房间底图。

### 9.2 底图必须保持的内容

- 房间、窗户、森林小路、墙灯、植物、信封、铃铛和家具。
- Morrow 的基础形象、当前姿态、光影关系和场景透视。
- 用户提供底图中的固定环境光、材质与构图。

除非用户明确要求修改底图，否则工程和后续视觉任务不得重新生成、重画、裁切或局部替换以上内容。

### 9.3 平台适配边界

- Web、小程序和 App 共用状态、文案、组件层级与视觉 token。
- 平台适配层只处理安全区、系统状态栏、录音授权、触控反馈和尺寸换算，不改变业务优先级。
- 母版比例变化时重新计算留白和组件位置，不机械裁切；Morrow 必须保持核心视觉焦点。

## 10. 方向对比与推荐结论

| 方向 | 优点 | 风险 | 结论 |
|---|---|---|---|
| 柔软房间陪伴感 | 角色与长期陪伴最自然，成人感稳定，UI 可克制叠加 | UI 过亮会破坏沉浸 | **选定为主方向** |
| 绘本生活感 | 亲和、叙事清楚 | 容易偏幼儿化，削弱长期成人陪伴感 | 不单独采用，仅保留柔和叙事节奏 |
| 轻幻想声音岛 | 声音碎片与月牙设定突出 | 容易变成强幻想游戏界面 | 不单独采用，仅保留金青色声音碎片和微光语言 |

最终采用“柔软房间陪伴感”为主体，吸收绘本方向的生活叙事与轻幻想方向的声音碎片／微光，不采用幼儿化插画皮肤或高饱和游戏化界面。
