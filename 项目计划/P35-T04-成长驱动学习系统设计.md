# P35-T04 成长驱动学习系统设计

## 1. 状态

✅ 已完成。六份设计交付文档已全部落盘于根目录，可直接用于编码与内容制作。

## 2. 任务目标

把"Morrow 认识世界并逐章学会表达"与"用户轻松但真实掌握英语"固化为可编码、可制作内容、可验证效果的学习系统。确立双轨难度：Morrow 的成长章节决定语言上限，用户水平只决定同一事件中的提示量与挑战方式，不跳章。

## 3. 任务范围

- 设计首次约 3 分钟轻量水平测试，覆盖基础词汇、简单听力、句意理解和自主造句，结果只生成初始用户难度档。
- 定义后续持续校准规则，用户可随时选择"简单一点"或"更有挑战"。
- 为七章分别定义 Morrow 的可理解词库、主动表达词库、搭配、句型与台词长度上限。
- 定义同一事件的基础、中等、进阶三类用户任务模板（认词/短句、完整造句、解释/改写/比较）。
- 建立覆盖七章的成长学习情景库，每章至少 8 个候选情景，轮换指认、听辨、选择、造句、纠错、执行、排序、比较、协作和回忆等交互结构。
- 将首两章已有 24 个事件逐项映射到学习情景类型、交互结构、目标词汇/句型、掌握证据和复现入口。
- 为第三至第七章准备与成长阶段匹配的候选情景。
- 用"幼年 Morrow 第一次认识苹果"制作完整样板，覆盖首次命名、完整句、特征描述、误认纠正、生活任务、偏好表达和跨场景迁移。
- 定义学习对象与掌握状态：初次接触、能识别、提示下会用、独立会用、迁移中、稳定掌握。
- 定义掌握证据与降级规则：照抄、查看译文、选项命中只算辅助；独立表达与新场景复现才提升掌握等级。
- 定义提示逐步退出策略与间隔复现调度规则。
- 明确学习数据的隐私与用户控制：不展示羞辱性评分，支持重测、纠正和删除。

## 4. 不包含

- 不实现学习系统的运行时代码（本任务只产出设计文档，编码在后续工程任务中完成）。
- 不批量制作第三至第七章的完整事件内容（本任务只列候选情景）。
- 不承诺穷尽全部英语词汇，只承诺成人生活核心高频词、常用搭配、主要句型与自主学习能力。

## 6. 验收标准

- 七章均有与 Morrow 成长阶段匹配的候选学习情景，每章至少 8 个，覆盖不少于 4 种交互结构。
- 情景库整体覆盖认识事物、执行动作、描述世界、表达自己、解决问题和社会沟通六类能力。
- 任意用户都从第一章开始，水平差异不会跳过或压缩 Morrow 的主要成长阶段。
- Morrow 不会说出当前成长阶段尚未解锁的主动词汇或句型。
- 查看中文、使用参考句、照抄选项只算辅助完成，不算独立掌握。
- 未掌握内容不阻塞剧情，但在后续合适场景自然复现。
- 数据结构和 API 足以保存水平档、学习对象、掌握证据、提示使用和复现计划。
