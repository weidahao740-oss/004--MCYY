# P4-T06-06 第一章 Web 功能界面适配

## 1. 状态

⬜ 未开始。等待 P4-T06-05 按已确认的新规则完成原型改造与体验验收。

## 2. 任务目标

把已确认的第一章界面、视觉和交互逻辑应用到 `english-pet` Web 测试端，接回真实的第一章内容、状态、语音、记忆和学习证据能力，完成手机优先的功能界面适配。

本任务同时负责把第一章验证通过的 UI 和交互实现为可配置、可复用的全产品基础框架。后续章节应通过内容、场景、状态、动作和素材配置接入，不能复制页面或另建一套基础交互。

## 3. 实施范围

- 仅接入第一章具体内容，但实现全产品通用功能框架。
- 改造首次进入、陪伴首页、情境互动、章节结算、成长、词语回声、设置与隐私相关界面。
- 接入中文操作与英文学习内容的分层规则；英文学习内容使用独立内容卡，实际操作按钮使用中文。
- 接入动态首页状态调度，禁止固定成窗边声音首页。
- 接入首两章 4 个基础场景的配置结构，并预留全产品 8 个基础场景；事件通过场景、镜头、时间／天气、道具和 Morrow 动作组合显示。
- 接入四个人生阶段、七个章节的展示数据结构；本期实现第一章章节结算，并预留跨阶段揭幕短片入口。
- 接入触摸、选择、听力确认、必修跟读、ASR／口语识别、逐级帮助和理解恢复。
- 跟读目标必须由真实录音识别通过后推进；移除“先听懂并继续”等替代完成入口。
- 接入第一章已发生世界变化、自动非敏感记忆和学习证据。
- 完成静音、`reduced motion`、麦克风拒绝、弱网、噪声、识别失败、刷新和重复提交处理；异常时保存为“跟读待完成”。
- 页面通过平台无关 API／API Client 访问数据，不直接访问 SQLite。

## 4. 验收环境

- 手机窄屏与触控为主。
- 桌面浏览器用于开发和内容调试。
- 软键盘、安全区域、屏幕阅读器、低运动和静音模式均需验证。

## 5. 交付物

- 已完成第一章功能界面适配的 Web 测试端。
- 第一章端到端功能验收记录。
- 页面、组件、动画、声音和数据状态的实现对照表。
- 小程序／App 可复用与需替换清单。

## 6. 验收标准

- 第一章首次体验、日常陪伴、情境互动和自然复现完整走通。
- 首页状态动态调度，且一次只出现一个主要状态。
- 用户能明确分辨中文操作和英文学习内容；不存在英文功能按钮与英文学习内容混用。
- 第一章事件使用与学习内容匹配的生活场景，且不为每个事件复制页面或整套背景。
- 成长页显示当前人生阶段、当前章节和已发生变化；第一章完成后显示章节结算，但不错误触发跨阶段短片。
- 所有必修跟读节点必须由真实录音和口语识别通过后推进，没有点击或文字替代完成入口。
- 口语识别以内容可被理解为标准，不因可接受口音差异误判失败。
- 跟读未通过时依次提供重听、慢速、音节提示、回听和重试。
- 麦克风拒绝、弱网、环境噪音和识别服务失败时保存为“跟读待完成”，允许暂停恢复但不结算为完成。
- 主要互动不依赖连续选择题。
- 加载、空内容、失败、弱网、权限拒绝和恢复均有清楚中文说明。
- 第二章及以后具体内容不影响本轮验收，也不被错误展示。
- 不新增云端基础设施，不启动小程序或 App 工程。
