# P5-T01 首个正式移动端（微信小程序先行）

## 1. 状态

⬜ 未开始。需等 Web 全页面、UI 与跨平台兼容（P4-T06）完成后启动；微信小程序先行，App 后续。云端基础设施（P4-T07）按正式联调需要解冻，不再作为讨论和完善 Web 界面的前置条件。

## 2. 任务目标

完成首个正式移动端（微信小程序先行，App 后续），上线"出生与苏醒"与"童年探索"两章及固定对话主题，通过正式环境发布检查。

## 3. 任务范围

- 完成微信小程序全中文 UI：账号、Morrow 主页、事件、对话、记忆、共同记忆和设置。
- 完成英文内容"查看中文 / 收起中文"。
- 完成录音授权、ASR 转写、修改确认、文字回退和弱网恢复。
- 完成预制音频播放、缓存、重听和 1.0×/0.8×/0.6× 变速播放。
- 上线"出生与苏醒"和"童年探索"两章完整主线。
- 上线 8—12 个固定对话主题。
- 完成隐私说明、用户协议、账号注销和问题反馈入口。
- 建立版本号、内容版本号、发布说明和回滚方式。
- 发布至少一个正式移动端。

## 4. 不包含

- 当前不启动：P4-T06 的 Web 页面、UI、业务流程和跨平台兼容未完成前，不创建小程序或 App 工程。
- 不把 Web 版本作为正式首发产品。
- 不做多宠物抽卡、排行榜、PK、付费系统、开放式生成剧情。
- 不做音素级发音评分和实时电话式连续语音。

## 6. 验收标准

- 至少一个正式移动端可安装或访问。
- 首两章主线、语音、翻译和记忆闭环在正式环境可运行。
- 隐私与账号删除功能可用。
- 监控、备份、成本告警和回滚可用。
- 客户端不含任何服务密钥，日志脱敏。
- 每个事件至少 2—3 条有效分支，所有主要英文内容有经人工检查的中文译文和对应音频。
