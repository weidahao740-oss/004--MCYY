# P4-T06-05 全产品关键流程原型演示说明（第一章样板）

> 原型目录：`C:\004-MCYY\morrow-ui-prototype`
> 本原型用于验证整个产品共用的页面骨架、导航、状态、组件和核心交互；当前用第一章真实内容作为首轮样板，不代表原型范围只限第一章。暂不接真实数据库、正式 API、账号或真实语音服务，不修改 `english-pet`。

## 演示路径

1. **首次相遇**：中文欢迎 → Morrow 苏醒 → 自我介绍 → 先观察/触摸耳朵、窗边或铃铛 → 第一次自由英语表达 → Morrow 复述理解 → 用户确认或修改 → 触摸灯/植物/小铃铛 → 用可编辑英语确认选择 → 房间变化 → 回到陪伴首页。
2. **日常陪伴**：首页一次只显示一个生活状态；点击 Morrow 获得即时反应；Morrow 在合适时机给出唯一的下一段预设互动；用户也可以“安静待一会”。
3. **窗边声音课程**：首页接受 Morrow 邀请 → 看懂场景 → 认识 `window` → 理解 `by the window` → 认识 `bell` → 搭建固定句型 → 听力确认 → 跟读或先听懂 → 场景结果 → 结束层。
4. **语音路径**：语音只用于预定句子跟读或识别确认，不提供开放聊天；识别失败时可用点击或文字选项完成同一步骤。
5. **帮助恢复**：帮助只围绕当前预定词语和句型，依次提供关键词、骨架、完整参考句和恢复选项。
6. **暂停恢复**：情境页右上“暂停” → 回到房间 → 首页出现“上次停在窗边” → 继续刚才。
7. **成长与词语回声**：底部导航进入成长、词语回声；内容仅展示已经发生的事实与已经遇见的表达。
8. **异常回退**：表达层可模拟麦克风权限拒绝和网络中断；两者均保留文字路径和当前草稿。
9. **重置体验**：设置 → “重新体验产品原型”，清空本地原型进度。

## 原型边界

- 使用冻结房间底图，UI 为可编辑前端层。
- 语音、ASR、网络失败均为交互状态模拟，不调用真实服务。
- 状态只保存在当前浏览器 `localStorage`，换浏览器或设备不共享。
