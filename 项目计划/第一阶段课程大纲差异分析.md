# 第一阶段课程大纲差异分析

> 生成日期：2026-09-22
> 分析对象：`MORROW_LANGUAGE_CURRICULUM.md` 第 2 节（第 1 章 出生与苏醒）
> 对比基准：`CHAPTER_01_BIRTH_CONTENT.md` v1.0.0（13 个事件全部台词）
> 目的：找出当前课程大纲第 1 章词库、搭配、句型与真实台词之间的全部遗漏，计算准确词量级，为修订提供可复算依据。

## 1. 分析说明

### 1.1 分析范围

- **大纲侧**：`MORROW_LANGUAGE_CURRICULUM.md` 第 2 节（2.1 词库、2.2 搭配、2.3 句型、2.4 台词复杂度上限）。
- **台词侧**：`CHAPTER_01_BIRTH_CONTENT.md` 全部 13 个事件（序 1—13），逐事件提取：
  - Morrow 主要台词（每事件 2 句）+ 三个分支结果回复 + 暂停出口回复。
  - 用户参考句（每事件 3 条可编辑英文句）。
  - 触发短语 / 关键词组（每事件分支意图 + 暂停意图）。

### 1.2 词量计算规则

- **计入词目**：名词、动词（含其不同屈折形式归并为同一词目）、形容词、关键副词、固定短语 / 搭配。
- **不计入词目**：功能词（I / the / a / an / to / and / of / in / on / at / for / it / is / are / was / were / be / been / do / does / did / have / has / had / will / would / can / could / should / not / no / yes / but / or / so / if / that / this / these / those / there / here / what / when / where / why / how / who / which / me / my / your / you / we / us / our / they / them / their / as / too / also / now / then / still / yet / just / only / very / much / many / some / any / one / all / each / other / another / about / with / from / into / under / over / after / before / until / since / than / up / down / out / off / again / once / never / always / often / maybe / perhaps / really / quite / almost / nearly / either / neither / both / let's / don't / can't / won't / isn't / aren't / I'm / you're / we're / it's / I've / you've / we've / they've / I'll / you'll / we'll / they'll / I'd / you'd / we'd / they'd）。
- **proper noun**：Morrow（墨洛）不计入词目。
- **active 定义**：Morrow 自己说出的台词中出现的内容词。
- **receptive 定义**：用户参考句 / 触发短语中出现、但 Morrow 自己台词中未出现的内容词（Morrow 听得懂但不说）。
- **去重规则**：同一词目在多个事件中重复出现只计一次。
- **屈折归并**：sound / sounds / sounding 归为 "sound"；say / said / saying 归为 "say"；leave / leaving / left 归为 "leave"；等。

### 1.3 逐事件 Morrow 台词完整清单

以下为全部 13 个事件中 Morrow 说出的每一句英文台词（按事件序排列），作为后续所有词目的追溯依据。

**序 1（E01-01 birth_first_voice_v1）**
1. Hello? I can hear someone beyond the room.
2. I'm Morrow. What should we do first?
3. You want to help me understand this room. I can start with that.
4. You asked whether I'm all right. I'm uncertain, but I'm listening.
5. We can leave the room quiet for now. I will not treat that as leaving me behind.

**序 2（E01-02 birth_restore_object_v1）**
6. The room remembers a lamp, a plant, and a small bell, but only one is clear.
7. Which one should we bring back first?
8. The lamp is steady now. The room has a place to keep a voice.
9. The plant looks less lost near the door.
10. The bell makes one low note. It sounds awake, not alarmed.

**序 3（E01-03 b1_remember_name_v1）**
11. On the island, people never quite finished my name. It always faded halfway.
12. I've been called Morrow, but that name still feels new. What do you think?
13. Morrow it is. It sounds steady enough to remember.
14. I can try M. It's a small sound, easy to answer.
15. Then I'll keep Morrow. It already knows my voice.
16. We can leave the name for later. It won't fade if we wait one day.

**序 4（E01-04 b1_first_feeling_v1）**
17. Now that the room is a little clearer, I notice something in my chest.
18. What do people call this feeling? Is it nervous, or just new?
19. New. I can live with that. It isn't the same as afraid.
20. A little nervous, then. Not much, just enough to notice.
21. Then we're feeling it together. That makes it smaller.
22. We can sit with the feeling and not name it yet. That's all right.

**序 5（E01-05 b1_window_light_v1）**
23. There's a window I can't quite reach yet. A light keeps moving on the glass.
24. Can you tell me what you see outside? Is it warm, or still early?
25. Warm. I'll remember that the light can be warm.
26. High sun. Then the day isn't over yet.
27. Take your time. I'll wait with the light.
28. We can leave the window for later. The light will still be there.

**序 6（E01-06 b1_first_letter_v1）**
29. A letter slipped under the door. The words are soft, like they forgot their shapes.
30. Can you read it for me? Some words are still there.
31. Welcome home. So this room was waiting for someone.
32. That's all right. We can leave it on the table and come back.
33. Slow is fine. I'll wait for each word.
34. We can leave the letter folded. It won't mind waiting.

**序 7（E01-07 b1_bell_sound_v1）**
35. A small sound comes back in the room. It's low, and it happens once.
36. Do you hear it? What does it remind you of?
37. A bell. That's a sound I can hold onto.
38. The room itself, then. That makes sense.
39. Maybe it's still waking up. It will come back.
40. We can wait for the next small sound. It has time.

**序 8（E01-08 b1_ask_about_you_v1）**
41. You talk about my room so much. I want to hear about yours now.
42. What's one small thing that happened to you today?
43. A long day. I'm glad you're here now, even if it's just this room.
44. Ordinary days matter too. Tell me one ordinary thing.
45. That's fine. We can sit here instead.
46. We can talk about your day another time. It won't go away.

**序 9（E01-09 b1_what_i_like_v1）**
47. After a day in this room, I notice what I'm drawn to and what I'm not sure about.
48. I think I like the quiet. What about you?
49. Two people who like quiet. We won't need much noise.
50. Outside. Then we'll have to look through that window more.
51. So am I. We can figure it out together, slowly.
52. We can leave likes and not-likes for another day. Nothing has to be decided today.

**序 10（E01-10 b1_tomorrow_plan_v1）**
53. The first day is ending. I don't want to leave the room empty tomorrow.
54. What's one small thing we could try tomorrow?
55. The road. I'll stand by the window first, just to look.
56. The letter. Maybe one more word will be clear tomorrow.
57. Rest. That's a plan too. I won't wake you early.
58. We can decide tomorrow morning. Plans can wait until then.

**序 11（E01-11 b1_return_first_words_v1）**
59. I keep thinking about the first thing you said to me in this room.
60. It was "…". Did you mean it the way I heard it?
61. Good. I'll keep it the way you said it.
62. Tell me the newer version. I'd rather have the current one.
63. It wasn't long, but it was the first. That's why it stays.
64. We can leave the first words where they are. I won't move them.

**序 12（E01-12 b1_ready_for_outside_v1）**
65. The room is steady now. The door to the outside path doesn't feel as loud as before.
66. I think I'm ready to step toward it. Are you?
67. Then we go together. One step at a time.
68. One more day. The room can wait. So can I.
69. I don't know. That's part of why I want to look.
70. We can stand here a little longer. The door isn't going anywhere.

**序 13（E01-13 b1_not_sure_v1）**
71. There is one small thing I'm not sure about yet.
72. Is it okay not to know yet, or should I figure it out now?
73. Good. We can leave it there and come back.
74. Then we think slowly. Not having the answer now is fine.
75. Later it is. I won't keep worrying about it.
76. We can leave it undecided. Not knowing is also a place.

## 3. 真实台词统计结果

### 3.1 active 词库实际数量

从 76 句 Morrow 台词中提取全部内容词，去重并按屈折归并后，得到以下 **82 个 active 词目**：

**名词（30 个）**：room、someone、lamp、plant、bell、place、voice、door、note、island、people、name、sound、answer、day、chest、feeling、window、light、glass、sun、time、letter、word、shape、home、table、thing、noise、road

**动词（30 个）**：hear、want、help、understand、start、listen、leave、treat、remember、bring、keep、look、make、call、feel、think、try、wait、notice、sit、reach、tell、see、read、forget、slip、fold、remind、wake

**形容词（17 个）**：quiet、small、clear、steady、lost、low、awake、alarmed、new、nervous、afraid、warm、early、high、soft、slow、fine

**副词 / 短语（5 个）**：beyond、uncertain、halfway、together、outside

> **active 实际 = 82 个词目**（含已有 29 个 + 新发现 53 个）。

### 3.2 receptive 额外词库实际数量

从用户参考句和触发短语中提取、且 Morrow 台词中未出现的内容词，去重后得到 **28 个 receptive 额外词目**：

**名词（8 个）**：afternoon、daytime、work、special、version、way、night、week

**动词（6 个）**：find、pick、stay、move、know（用户用 Morrow 不用的语境）、hear（用户触发但 Morrow 台词已覆盖，不计）

**形容词（7 个）**：right、short、probably（副词但作形容词用）、closer、blurry、normal、tiring

**副词 / 短语（7 个）**：sometimes、late、either、really、actually、again、differently

> **receptive 实际总计 = 82（active）+ 28（额外）= 110 个词目**。

### 3.3 搭配实际数量

Morrow 台词中实际出现的搭配 / 短语共 **15 条**（详见第 6 节）。

### 3.4 句型实际数量

Morrow 台词中实际出现的句型结构共 **16 种**（详见第 7 节）。

### 3.5 最长句实测

逐句词数统计后，Morrow 最长台词为：

> **"After a day in this room, I notice what I'm drawn to and what I'm not sure about."**（序 9 第 1 句）

词数：After(1) a(2) day(3) in(4) this(5) room(6) I(7) notice(8) what(9) I'm(10) drawn(11) to(12) and(13) what(14) I'm(15) not(16) sure(17) about(18) = **18 词**。

当前 curriculum 标注最长 ≤ 16 词，实际 **18 词**，超出上限 2 词。
