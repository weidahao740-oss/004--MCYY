## 1. 文档说明与设计原则

### 1.1 文档定位

本文档把第一章 "出生与苏醒" 的已确认内容，收敛为一套可直接进入视觉设计、可点击原型和 Web 功能适配的交互规格。它回答的问题是：**用户在第一章每一步看见什么、能做什么、Morrow 如何回应、系统如何调度和记录、异常如何恢复。**

### 1.3 第一章作为全产品通用 UI 基准的声明



* 第一章定下的主导航、页面职责、动态首页、情境互动状态机、输入方式、逐级帮助、反馈、成长回顾、词语回声、设置和异常恢复逻辑，后续章节默认复用。

* 后续章节只增加内容、场景、物品、台词、Morrow 状态 / 动作、声音和少量特殊能力，**不重新设计整套交互**。

* 第一章 13 个事件共用统一的情境互动结构，通过状态、台词、物品、动作和帮助内容变化注入，**绝不为 13 个事件复制 13 套页面**。

* 若后续章节迫使项目大规模修改主导航、首页结构、情境互动模板或输入 / 反馈方式，应先视为第一章通用设计覆盖不足，回到本规格评审，而不是直接为单章制作独立界面体系。

### 1.3.1 最新产品决策：取消开放说话（2026-09-29）

- 取消陪伴首页和情境页的“和 Morrow 说话”功能，不提供开放聊天、开放文字输入或课程外自由提问。
- 所有学习内容均为预先制作并版本化的固定内容，包括 Morrow 台词、中文译文、题型、词语、句型、选项、正确/错误反馈、帮助和复现路径。
- Morrow 依据章节、已完成步骤、学习证据、难度档和冷却规则安排用户当前学习内容；用户不需要自己找课程或决定学什么。
- 用户的参与方式限定为课程内的触摸、选择、排序、填词、跟读、听力确认、查看中文、重听、暂停和安静陪伴。
- 语音仅用于预定句子的跟读或识别确认，不用于开放对话；识别失败时使用点击或文字选项继续。
- 本条为最新决策，替代本文后续仍残留的“自由表达”“自由输入”“快速表达”“和 Morrow 说话”等旧口径；这些旧口径不得进入实现。

### 1.4 核心设计原则



| 原则    | 含义                              | 前台表现                             |
| ----- | ------------------------------- | -------------------------------- |
| 隐藏事件  | 事件、任务、课程、掌握分数、成长门槛全部在后台         | 用户看不到事件目录、事件编号、任务卡、进度条           |
| 动态首页  | Morrow 的生活状态由四层状态调度器选择，不固定成单一入口 | 每次打开先看见 Morrow 正在做什么，一次只展示一个主要状态 |
| 自然互动  | 观察→触摸→自由表达→主动请求帮助→连续无法理解才出现候选   | 不把主要互动写成连续选择题                    |
| 不惩罚   | 用户可以只陪伴、暂停、离开、说 "不想学"           | 不扣关系值、不写负向状态、不出现饥饿 / 生病 / 负罪感    |
| 不展示未来 | 不预告下一阶段、未学词汇、解锁条件、还差多少          | 成长页和词语回声页只展示已经发生的事实              |

### 1.5 绝对禁止（全章通用）



* 不修改 `english-pet`。

* 不画高保真 UI，不生成角色或场景图片。

* 不新增事件目录、课程列表和成长进度条。

* 不把首页固定为 "窗边听声音"。

* 不在前台展示未来阶段或未学内容。

* 不使用打卡、金币、经验、饥饿、生病、负罪感。

* 不要求用户逐条审核或管理生活记忆。

* 不把主要互动写成连续选择题。

## 2. 第一章页面清单与页面职责

### 2.1 页面总表



| #   | 页面              | 页面形态             | 一句话职责                                      |
| --- | --------------- | ---------------- | ------------------------------------------ |
| P1  | 初次进入页           | 独立页面             | 新用户第一屏，不要求注册 / 问卷 / 测水平                    |
| P2  | 初次相遇流程          | 独立连续流程页（内部多步骤）   | 用一条连续流程完成相遇、第一次表达、第一次被理解、第一次改变房间、记忆确认和回到房间 |
| P3  | 陪伴首页（Morrow 房间） | 独立页面，默认落点        | 用户每次打开后的默认落点，先感受 Morrow 当前在做什么             |
| P4  | 情境互动页           | 独立页面             | 承载主线事件、日常话题和记忆回访；所有 13 个事件共用               |
| P5  | 快速表达层           | 底部上拉覆盖层          | 随时直接和 Morrow 说话，不跳转到聊天页面                   |
| P6  | 逐级帮助层           | 场景区内折叠展开器        | 用户主动请求或连续无法理解时，逐级提供关键词 / 骨架 / 参考句 / 候选意思   |
| P7  | 互动结束层           | 底部上拉总结层          | 一次互动完成后简短说明发生了什么，不跳成绩报告                    |
| P8  | 成长页             | 独立页面（底部导航之一）     | 只回看第一章已经发生的变化，不预告未来                        |
| P9  | 词语回声页           | 独立页面（底部导航之一）     | 只复习第一章已经遇见的词、搭配和句型                         |
| P10 | 设置与隐私页          | 独立页面（从陪伴首页右上角进入） | 低频配置、记忆与数据说明、账号与设备、关于 Morrow               |

### 2.2 逐页职责清单

#### P1 初次进入页



| 项           | 内容                                                                                                     |
| ----------- | ------------------------------------------------------------------------------------------------------ |
| 页面职责        | 让新用户直接开始体验，不在第一次交流前要求注册、填问卷或做水平测试                                                                      |
| 进入条件        | 新访客首次打开产品；本机无任何访客数据                                                                                    |
| 离开条件        | 用户点击主操作或次操作，进入 P2                                                                                      |
| 核心内容        | 安静房间主视觉（只见呼吸光、耳朵轮廓、窗帘微动）；两行中文欢迎文字“欢迎来到 Morrow 的成长世界”与“房间里有一个微弱的声音。”；唯一主操作“去看看是谁”；右上角低强调声音开关 |
| Morrow 可见反应 | 不完整展示 Morrow，只显示轮廓、呼吸光或眼睛，保留第一次相遇感                                                                     |
| 不允许出现       | 两个进入同一流程的重复按钮；“暂时离开”按钮；说明性小字；邮箱密码表单；学习目标问卷；等级选择；多宠物选择；付费入口；底部导航 |

#### P2 初次相遇流程



| 项           | 内容                                                                |
| ----------- | ----------------------------------------------------------------- |
| 页面职责        | 用一条连续流程完成相遇、第一次表达、第一次被理解、第一次改变房间、记忆确认和第一篇共同记忆                     |
| 页面形态        | 一个连续页面和内部步骤，不为每一步建立独立导航页                                          |
| 进入条件        | 从 P1 进入；已有本机访客数据时不进入本流程                                           |
| 离开条件        | 完成序 1（苏醒后的第一句话）和序 2（让第一件东西清晰起来）后自动回到 P3                           |
| 核心内容        | 7 步流程（见第 5 节）：Morrow 苏醒→称呼提供（可选）→第一次英语表达→理解确认→第一件房间物品恢复→自动记忆→回到房间 |
| Morrow 可见反应 | 从轮廓到完整出现；苏醒第一句；邀请表达；按用户意思行动；物品恢复；结束语                              |
| 不允许出现       | 完整底部导航；事件目录；课程列表；成长进度；逐条记忆审核卡                                     |

#### P3 陪伴首页（Morrow 房间）



| 项           | 内容                                                                                                                              |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 页面职责        | 用户每次打开产品后的默认落点。用户先感受到 Morrow 当前在做什么，再决定是否互动                                                                                     |
| 进入条件        | ①新用户完成 P2 后首次进入；②返回用户打开产品；③从 P4/P7/P8/P9/P10 返回                                                                                 |
| 离开条件        | ①触摸 Morrow / 房间物品→留在首页显示即时反应；②"和 Morrow 说话"→P5；③Morrow 主动邀请 / 环境变化→P4；④右上角→P10；⑤底部 "成长"→P8；⑥底部 "词语回声"→P9                        |
| 核心内容三层      | 第一层：Morrow 和房间（Morrow 居中，当前表情 / 姿态 / 尾巴微光；房间显示已恢复物品）；第二层：Morrow 当前想说的一句话（只显示一个当前话题）；第三层：主要互动（"和 Morrow 说话"+"看看发生了什么"），辅助动作按状态出现 |
| Morrow 可见反应 | 眼神 / 耳朵方向变化；尾巴微光变亮或变缓；一句简短回应；房间物品微小变化；声音灯恢复一小格                                                                                  |
| 不允许出现       | 一次展示十几个事件卡；金币 / 经验 / 连续签到；宠物饥饿值或健康惩罚；与 Morrow 无关的数据仪表盘；底部导航（新用户完成 P2 前不显示）                                                      |

#### P4 情境互动页



| 项           | 内容                                                                                                                               |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 页面职责        | 承载主线事件、日常话题和记忆回访。用户是在一个场景中和 Morrow 一起做事，而不是阅读题目后选答案                                                                              |
| 进入条件        | ①陪伴首页 Morrow 主动邀请 / 环境变化；②用户点击 "看看发生了什么"；③从暂停点恢复                                                                                 |
| 离开条件        | ①互动完成→P7→P3；②暂停→P3；③查看刚学过的表达→P9                                                                                                  |
| 核心内容三区      | 场景区（Morrow + 当前环境，可互动物品有轻微提示）；Morrow 回应区（一到两句英文台词 + 播放 / 重听 / 三档语速 /"查看中文" 默认收起）；用户行动区（触摸场景→自由文字 / 录音→情境动作→主动展开参考表达→系统无法理解时候选意思） |
| Morrow 可见反应 | 按用户表达的意思行动：听懂则靠近 / 尾巴亮起 / 继续情境；有歧义则复述并问一个澄清问题；没听懂则说明没听懂哪部分并提供恢复入口                                                                |
| 不允许出现       | 底部导航（隐藏）；答题式堆叠选项；事件编号；"下一事件" 预告；成绩页                                                                                              |

#### P5 快速表达层



| 项           | 内容                                                |
| ----------- | ------------------------------------------------- |
| 页面职责        | 让用户随时直接和 Morrow 说话，不需要跳转到单独聊天页面                   |
| 页面形态        | 手机底部上拉层，不是完整新页面                                   |
| 进入条件        | ①陪伴首页点击 "和 Morrow 说话"；②情境互动页点击输入区；③点击麦克风按钮        |
| 离开条件        | ①发送后关闭输入层，回到 Morrow 和当前场景，直接看到 Morrow 反应；②用户收起上拉层 |
| 核心内容        | 可编辑文字输入框；按住说话；ASR 转写确认；"查看简单表达" 折叠入口；发送按钮         |
| Morrow 可见反应 | 发送后先听完不打断，按意思行动，不在过程中连续纠错                         |
| 不允许出现       | 消息列表式聊天界面；发送后跳转到新页面；参考句默认展开                       |

#### P6 逐级帮助层



| 项           | 内容                                               |
| ----------- | ------------------------------------------------ |
| 页面职责        | 用户主动请求或连续无法理解时，逐级提供帮助，不把帮助当主流程                   |
| 页面形态        | 场景区内折叠展开器，不上拉整层                                  |
| 进入条件        | ①用户点击 "给我一点帮助"；②系统连续两次无法可靠理解                     |
| 离开条件        | ①用户收起帮助；②用户使用某级帮助后发送；③用户改用文字 / 语音 / 慢速 / 查看中文    |
| 核心内容        | 四级帮助（0 无提示→1 关键词→2 句型骨架→3 可编辑参考句→4 候选意思），详见第 9 节 |
| Morrow 可见反应 | 用户使用帮助不受惩罚，但帮助层级会影响学习证据级别                        |
| 不允许出现       | 帮助默认展开；候选意思作为主流程；使用帮助后扣关系值                       |

#### P7 互动结束层



| 项           | 内容                                                                                   |
| ----------- | ------------------------------------------------------------------------------------ |
| 页面职责        | 在一次互动完成后，用简短方式说明 "发生了什么"，而不是突然跳到学习报告                                                 |
| 页面形态        | 情境页底部上拉总结层，用户可直接返回房间                                                                 |
| 进入条件        | 情境互动完成或用户选择收束                                                                        |
| 离开条件        | ①"回到房间"→P3；②"再听一次"→留在 P4；③查看刚学过的表达→P9                                                |
| 核心内容顺序      | Morrow 一句结束回应→房间 / 动作 / 关系变化→用户刚才成功表达的一句→一条更自然的说法（仅在确有价值时）→自动留下本次非敏感互动回忆和学习证据→"回到房间" |
| Morrow 可见反应 | 肩背放松；尾巴光点聚成稳定一小段；结束台词                                                                |
| 不允许出现       | 分数；错误列表；正确率；逐条记忆审核卡；未来预告                                                             |

#### P8 成长页



| 项           | 内容                                                                                 |
| ----------- | ---------------------------------------------------------------------------------- |
| 页面职责        | 让用户回看 Morrow 已经发生的成长和你们已经共同走过的变化，但不透露未来内容                                          |
| 进入条件        | 底部导航点击 "成长"（新用户完成 P2 后才显示）                                                         |
| 离开条件        | 返回 P3                                                                              |
| 核心内容        | Morrow 当前形态 / 姿态 / 语言变化；已获得的生活能力；已恢复的房间物品 / 声音 / 活动范围；已发生的成长瞬间和共同回忆；只用已发生的事实讲述成长   |
| Morrow 可见反应 | 本页以回顾卡片为主，不触发新互动                                                                   |
| 不允许出现       | 下一阶段名称 / 画面；"正在准备什么"；还差多少词 / 事件 / 互动；进度条 / 成长百分比 / 升级条件；尚未发生的新地点 / 新动作 / 新角色 / 新内容 |

#### P9 词语回声页



| 项           | 内容                                                                 |
| ----------- | ------------------------------------------------------------------ |
| 页面职责        | 让用户复习自己已经接触过的单词、搭配和句型，并看到这些表达曾在哪些真实互动中出现；绝不提前展示未来阶段词汇              |
| 进入条件        | 底部导航点击 "词语回声"（新用户完成 P2 后才显示）；从 P7"查看刚学过的表达" 进入                     |
| 离开条件        | 返回 P3                                                              |
| 核心内容三分类     | 最近遇见（最近在互动中接触过的词和短语）；还想再用（系统判断仍需要复现的词、搭配和句型）；已经很熟（已在多个场景中独立使用过的内容） |
| 复习方式        | 听音辨义；看场景回忆表达；跟 Morrow 再说一次；把旧词放入新的自由句子                             |
| Morrow 可见反应 | 复习时 Morrow 按固定台词回应，不创造新内容                                          |
| 不允许出现       | 未学内容；"后面会学什么"；羞辱性分数；正确率；待办清单                                       |

#### P10 设置与隐私页

### 4.1 四层状态定义



| 层级 | 名称     | 作用               | 生命周期                 | 第一章范围内取值清单                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| -- | ------ | ---------------- | -------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

### 4.2 调度优先级与选择算法

每次打开产品时，状态调度器按以下顺序选择**一个**最高优先级状态：



```
1\. 可恢复的未完成情境

&#x20;  └─ 上次暂停且仍适合继续的事件（recoverable=true 的事件状态）

&#x20;     └─ 延续该情境，但允许用户暂不继续

2\. 已发生的成长变化

&#x20;  └─ 存在尚未被前台呈现的 L1 长期成长状态变化

&#x20;     └─ 展示该变化带来的生活状态（如 Morrow 第一次走近窗边）

3\. 语义匹配的记忆/学习复现

&#x20;  └─ 存在到期且与当前场景语义匹配的旧词/旧句/共同记忆

&#x20;     └─ 生成自然回访状态（如 E01-11 记住你说过的第一句）

4\. 本章日常状态池

&#x20;  └─ 从第一章日常状态池中选择一个近期未连续出现的状态

&#x20;     └─ 触发对应日常事件（E01-04/06/07/08/13）或自由陪伴

5\. 自由陪伴

&#x20;  └─ 没有合适内容时进入自由陪伴，不硬塞教学
```

### 4.3 调度规则



| 规则           | 说明                                    |
| ------------ | ------------------------------------- |
| 一次只展示一个主要状态  | 不同时堆多个情境或任务                           |
| 同一日常状态相邻不重复  | 日常事件相邻两次不取同一事件；冷却期内不重复                |
| 短时返回延续原动作    | 距离上次互动较短时，Morrow 延续刚才的动作和话题，不假装经过了很久  |
| 间隔数小时轻微变化    | 房间或 Morrow 姿态出现小变化，触发一个轻量日常互动         |
| 次日或更久可换新状态   | Morrow 有新的生活状态或章节变化，但不责备、不询问 "你为什么没来" |
| 长期未返回安静恢复    | 不一次补发多件事，不责备缺席，一次只给一个轻量互动机会           |
| 复现只能在语义合适时进入 | 不能为了复习强行改变 Morrow 正在做的事；没有合适语义就推迟     |
| 前台不显示调度痕迹    | 不显示状态来源、调度优先级、事件 ID、复现原因              |

### 4.4 打开间隔规则详表



| 打开间隔       | Morrow 行为        | 示例                                                           |
| ---------- | ---------------- | ------------------------------------------------------------ |
| 短暂返回（几分钟内） | 延续原动作和话题         | "I kept listening. The sound is still there."                |
| 间隔数小时      | 姿态或物品小变化，轻量日常互动  | Morrow 从窗边移动到架子旁，正在研究一个杯子                                    |
| 次日或更久      | 新的生活状态或章节变化，不责备  | "You are back. I found something near the window."           |
| 长期未返回      | 安静欢迎和状态恢复，不补发多件事 | "It has been quiet here. We can begin with one small thing." |

### 5.3 关键规则



* **称呼提供是可选的**：用户可以跳过，Morrow 不追问。

* **第一次英语表达**：默认提供 "打字告诉 Morrow" 和 "按住说话"，参考句默认收起。

* **理解确认**：Morrow 复述自己的理解，用户确认或修正；被否认内容不写入世界状态。

* **第一件房间物品恢复**：用户触摸灯 / 植物 / 铃铛的模糊轮廓，并用英语确认选择；这是真实剧情决定，允许出现选项。

* **自动记忆**：Morrow 自动记住本次非敏感互动和用户实际说过的话，不弹逐条记忆审核卡。

* **新用户完成初次相遇前不显示完整底部导航**。

* **初次相遇期间不展示事件目录、课程列表、成长进度**。

## 6. 返回用户日常循环

### 6.1 状态恢复逻辑



| 场景        | 恢复行为                                  |
| --------- | ------------------------------------- |
| 上次有未完成情境  | 优先恢复该情境（调度优先级 1），Morrow 延续倾听姿态与同一房间状态 |
| 上次已完成全部主线 | 从日常状态池或自由陪伴进入                         |
| 长期未返回     | 只安静恢复，不补发多个情境，不责备缺席                   |

### 6.2 日常陪伴的互动方式

按自然互动优先级从高到低：



1. **观察 Morrow 与场景**：用户先看 Morrow 在做什么、房间有什么变化。

2. **触摸 Morrow 或房间物品**：摸摸头、摸耳朵、碰一碰窗边、点一点已恢复的物品。

3. **自由文字或语音表达**：打开 P5 快速表达层，说一件小事。

4. **用户主动请求关键词和句型帮助**：点击 "给我一点帮助"。

5. **连续无法理解时才显示候选意思**：最多 3 个中文候选。

### 6.3 Morrow 主动互动的触发条件和形式



| 触发条件                | 主动互动形式                            |
| ------------------- | --------------------------------- |
| 用户刚打开应用             | Morrow 看向某个物品 / 主动靠近 / 先说一句话再等待用户 |
| 距离上次互动已到合适间隔        | 环境中出现一个新声音；Morrow 说一句话            |
| 上次留下未完成的小问题         | Morrow 自然提起那件事                    |
| 当前章节出现新物品 / 地点 / 声音 | Morrow 看向新物品，邀请用户一起看看             |
| 某个核心词或句型到了自然复现时间    | Morrow 在语义匹配的日常情境中自然带回旧表达         |
| 一条已确认共同记忆适合回访       | Morrow 主动回忆并引用（一次最多一条）            |

**页面只显示一个主要邀请**（如 "一起看看" 或 "告诉我一个小细节"），不堆多个任务卡。

### 6.3.1 用户打开应用后收到 Morrow 对话的双入口

用户首次打开或日常返回后，都可以通过两种方式收到 Morrow 的对话与行动提示。两种入口服务不同目的，不能同时抢占注意力。

#### 入口 A：Morrow 主动发起对话

适用于 Morrow 确实有一件当前想说、想分享或需要共同处理的小事。

- 画面中唯一具象角色是 Morrow；用户始终位于屏幕外，以触摸、文字和语音参与，不在画面中设置另一个“主角”形象。
- 表现形式：Morrow 先做动作（看向用户、靠近、看向物品或竖耳倾听），随后在 Morrow 头部附近或视线方向出现**场景内对话气泡**，气泡尾巴明确指向 Morrow；同步播放固定英文语音并显示英文字幕，人工中文译文默认收起。
- 不使用遮住整页、必须点击才能关闭的系统弹窗；主动对话不能让用户感觉被任务拦截。
- 气泡只承载一句当前台词和一个主要邀请。可使用：`一起看看`、`帮我听听`、`告诉我一个小细节`。不使用幼儿化或索取感过强的“快来帮帮我”。
- 用户可以点击主要邀请进入 P4 情境互动，也可以选择`稍后再说`、`安静待一会`、直接触摸场景或离开。
- 用户没有回应时，气泡约数秒后收成一行轻提示，不反复弹出、不连续播放语音、不制造负罪感。

首次打开的主动对话：

```text
中文欢迎与房间声音
→ Morrow 从轮廓中苏醒
→ Morrow 主动说第一句英语
→ 场景内对话气泡显示同一句字幕
→ 用户可继续、触摸场景、先看文字或暂时离开
```

日常打开的主动对话：

```text
进入陪伴首页
→ 先展示 Morrow 当前生活动作
→ 若状态需要主动交流，Morrow 说一句当前台词
→ 出现一个主要邀请
→ 用户继续则进入情境；拒绝或不回应则留在陪伴首页
```

#### 入口 B：用户自行探索并获得点击提示

适用于当前没有必须立即说出的台词，或用户还不熟悉“场景可以触摸”的阶段。

- Morrow、房间物品和声音来源可以成为触摸热区，但不长期显示按钮边框或任务图标。
- 可互动位置使用轻量视觉暗示：耳朵轻动、眼神转向、物品微光、窗帘摆动、声音波纹或一颗声音碎片靠近目标。
- 用户进入页面后暂未操作，可在页面底部安全区上方出现一次**半透明系统提示条**：`可以点点 Morrow 或房间里的东西试试看。`
- 探索提示条不是对话气泡：没有指向 Morrow 的气泡尾巴，不与英文字幕混用，使用中文系统提示样式，避免被理解成 Morrow 的台词。
- 提示条不遮挡 Morrow、房间物品、输入区或底部导航；用户开始触摸、说话或进入情境后立即淡出。
- 用户第一次成功点击某类热区后，系统视为已经学会该操作；后续主要保留动作和光效暗示，不每次重复文字教学。
- 点击不同位置会得到不同回应：触摸 Morrow 触发即时关系反应；触摸房间物品触发观察、声音或情境入口；点击空白处不报错、不推进事件。

#### 两种入口的优先级

```text
有必须恢复的未完成情境或重要主动台词
→ 先使用入口 A：Morrow 动作 + 一句场景内对话气泡
→ 台词结束或用户收起后，再允许入口 B 的热区暗示

没有需要主动说的话
→ 直接展示当前生活状态
→ 使用入口 B：动作、微光和必要时的一次轻提示，引导用户自行探索

用户已经开始触摸、输入或说话
→ 立即停止新提示和新主动气泡
→ 优先响应用户当前操作
```

#### 防打扰规则

- 同一时刻只允许一个主提示：主动对话气泡、探索文字提示、逐级帮助三者不能叠加。
- 用户主动操作的优先级高于系统提示；不在用户输入、录音或查看译文时弹出新对话。
- 主动邀请被拒绝后，本次打开不以另一种文案重复邀请同一件事。
- 长期返回可以有一句安静欢迎，但不一次补发多条对话。
- 关闭声音时，动作、字幕和文字提示仍完整可用。

## 8. 触摸、文字、语音与安静陪伴规则

### 8.1 触摸热区清单



| 热区                           | Morrow 身体动作      | 表情 / 眼神     | 尾巴 / 月牙 / 声音碎片  | 短音效       | 英语台词                                     | 学习证据                           |

### 8.2 连续触摸去重复规则

同一热区 **5 秒内**：



| 触摸次数     | 反应                                                          |
| -------- | ----------------------------------------------------------- |
| 第 1 次    | 完整动作 + 可选短台词                                                |
| 第 2 次    | 动作做变体，只发短音效，不重复原台词                                          |
| 第 3 次及以上 | 缩短为眼神 / 耳朵响应；Morrow 最多说一次 **I know you are here.**／我知道你在这里。 |
| 之后       | 进入 8 秒台词冷却                                                  |

连续触摸不扣关系值、不表现恼怒，也不产生重复学习证据。

## 9. 逐级帮助、零基础脚手架与理解恢复

### 9.0 零基础用户的默认渐进路径（2026-09-29 更新）

第一章不提供“和 Morrow 说话”的开放聊天入口，也不要求用户自行输入课程外内容。所有学习内容、台词、题型、选项、帮助、反馈和复现路径均预先编排，由 Morrow 根据章节、已完成状态、学习证据与冷却规则决定当前学习内容。

采用“多邻国式教学脚手架 + Morrow 生活情境”，借鉴小步教学、多通道理解、即时反馈、逐渐撤除提示与间隔复现，但不引入红心、经验值、连胜、排行榜、课程地图或惩罚式失败。

默认顺序：

1. **看懂情境**：先用画面、动作、声音及必要的中文说明，让用户知道发生了什么。
2. **听见短词**：Morrow 说一个与当前物体绑定的短词，如 `window`，同时看向并轻微突出窗户。
3. **理解短语**：扩展为 `by the window`，同屏提供人工中文，允许重听和慢速。
4. **动作回应**：用户通过点击或触摸证明理解，不要求立即说英语。
5. **选择目标词**：从本次预设词中选择 `window / sound / bell` 等内容，不输入课程外文本。
6. **句型搭建**：通过填词、排序或选择完成 `I hear a ___ by the window.` 等预设句型。
7. **跟读或听力确认**：用户可跟读预设句子，也可先完成听力理解；语音不用于开放聊天。
8. **换场景复现**：后续用风声、纸声或门边声音自然复现，而不是让用户自己找课程。

支持量按表现动态调整：

- **启蒙支持**：中文默认可见，动作优先，可用选择和单词完成；
- **基础支持**：中文默认收起，从短语和句型骨架开始；
- **自主练习**：从完整预设句与听力确认开始，减少提示，但仍不开放聊天。

系统根据用户实际表现逐渐撤掉帮助；用户可随时选择“简单一点”，不会受到惩罚。一次情境只突出 1—2 个核心表达，不能为了覆盖词表牺牲生活感。

### 9.1 四级课程内帮助体系



| 层级         | 出现条件                 | 用户看到什么                                                                 | 是否能形成独立使用证据                 |
| ---------- | -------------------- | ---------------------------------------------------------------------- | --------------------------- |
| 0. 无提示自由表达 | 默认                   | 空白文字框 / 语音入口                                                           | 是，前提是用户自行组织且意思正确            |
| 1. 关键词     | 用户点一次 "给我一点帮助"       | 该事件核心词（如 `sound` 声音；`window` 窗户；`bell` 铃铛；`listen` 听）                  | 否，最多形成识别或提示下使用              |
| 2. 句型骨架    | 用户再次请求帮助或首次表达无法匹配    | 句型骨架（如 `I hear ___ .`／`The sound is ___ .`／`Let's ___ again.`）         | 否，正确提交可形成提示下使用              |
| 3. 可编辑参考句  | 用户继续需要帮助             | 完整可编辑参考句（如 `I hear a soft sound by the window.`／`Let's listen again.`） | 原样提交不算独立；明显自行修改且意思正确可作为较弱证据 |
| 4. 候选意思    | 连续两次无法可靠理解，或存在两种接近意图 | 中文候选最多 3 个（如 `声音像铃铛`、`再听一次`、`走近窗边`）+ 可编辑英文参考句                          | 不算独立，只用于恢复流程                |

### 9.2 用户在任何层级都可以



* 收起帮助；

* 改用文字或语音；

* 慢速播放（1.0×/0.8×/0.6×）；

* 查看中文（默认收起，按需展开）；

* 以上操作不受惩罚。

### 9.3 理解恢复流程



| 理解结果    | Morrow 行为                                                  | 用户操作                  |
| ------- | ---------------------------------------------------------- | --------------------- |
| 意思清楚    | 直接按意思行动，不即时纠错                                              | 观看 Morrow 行动          |
| 有歧义     | 复述一个可能意思，只问一个澄清问题                                          | 确认、修改或重新说             |
| 完全没听懂   | 说明没听懂 "意思"（"I hear the words, but not the meaning."），保留原输入 | 重新说 / 打字 / 简单一点       |
| 连续两次没听懂 | 显示最多 3 个候选意思                                               | 明确确认后推进；只算辅助完成        |
| 用户否认理解  | "好的，刚才的理解不算。"                                              | 清除临时结果，回到最近确认状态；原句可编辑 |

**用户否认理解时**：清除临时结果，回到最近确认状态；被否认内容不写入世界状态、反馈或记忆。

## 10. 成长与词语回声的第一章展示边界

### 10.1 成长页（P8）展示边界



| 允许展示                            | 禁止展示                 |
| ------------------------------- | -------------------- |
| Morrow 当前已经呈现出来的形态、姿态和语言变化      | 下一阶段名称或画面            |
| 已经获得的生活能力（如能独立观察房间、能描述声音、会主动分享） | "正在准备什么"             |
| 已经恢复的房间物品、声音和活动范围               | 还差多少词、事件或互动          |
| 已经发生的成长瞬间和共同回忆                  | 进度条、成长百分比和升级条件       |
| 只用已发生的事实讲述成长                    | 尚未发生的新地点、新动作、新角色和新内容 |

**用户可见的成长表达示例**（只允许描述已经发生的事实）：



* Morrow 现在会朝声音的方向转动耳朵。

* Morrow 第一次走近了窗边。

* 房间里已经能听见一声清楚的低鸣。

* Morrow 已经学会独立走到窗边观察。

* 房间里恢复了新的声音和物品细节。

* Morrow 说话比刚醒来时更完整，也更愿意主动分享。

**成长由系统后台根据故事经历和学习质量自主发生，用户只能回看结果**，不能选择成长路线、点击升级或提前查看未来。

### 10.2 词语回声页（P9）展示边界

#### 三个分类及进入条件



| 分类   | 进入条件                                | 页面展示                                          |

| 变化          | 条件                          |

| 已经很熟 → 还想再用 | 长期（两周以上）未使用后再次遇到时需要提示       |

#### 复习方式



1. 听音辨义。

2. 看场景回忆表达。

3. 跟 Morrow 再说一次。

4. 把旧词放入新的自由句子。

#### 禁止展示



* 未学内容；

* "后面会学什么"；

* 羞辱性分数；

* 正确率；

* 待办清单。
