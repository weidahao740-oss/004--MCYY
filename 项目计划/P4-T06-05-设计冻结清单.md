# P4-T06-05 进入正式 Web 改造的设计冻结清单

> 状态：产品规则已确认，等待落实到可点击原型并完成体验验收后正式冻结。冻结对象是全产品通用 UI、视觉、场景接入和核心交互；第一章仅作为首轮内容样板。

## 已确认可冻结：剧情无关层

- 当前原型的页面结构、主导航、气泡与中文展开、按钮样式和位置、按钮点击手势、场景热点、播放倍速、麦克风真实跟读、暂停恢复与异常处理可以先冻结，不等待具体剧情文案。
- 通用教学状态机可以先冻结：情境理解 → 按真实需要教学并跟读新词／语块 → 分块听读 → 整句跟读 → 结果。剧情变化只替换教学内容和步骤配置，不推倒状态机。
- 按钮视觉、位置和交互语义冻结，不代表按钮文案冻结；按钮文字可随剧情持续调整。

## 剧情审定后替换：内容层

- 可替换内容包括按钮文案、Morrow 中英文台词、自然中文理解、中文行动提示、目标句、新词／语块、分支结果、语音和物品状态。
- 每个事件实际教学步数由自然目标句与用户已有学习证据决定：没有新成分就压缩，出现新成分才展开；不为凑教学步骤强塞内容。

## 其他可直接冻结

- 主导航固定为：陪伴 / 成长 / 词语回声；设置仅从陪伴首页右上进入。
- P1–P10 页面职责及 P5/P6/P7 覆盖层形态。
- 首页四类关键状态：主动邀请、首次探索、普通自由陪伴、暂停恢复；同一时刻只展示一个主提示。
- 中文负责导航、操作、状态、提示与异常恢复；英文只承载 Morrow 台词和目标学习内容。英文选择内容放在学习内容卡内，操作按钮仍使用中文。
- 情境互动统一使用同一通用骨架，不为每个事件复制页面；事件必须进入与学习内容匹配的生活场景。
- 首两章基础场景固定为 4 类：Morrow 的房间、窗边观察区、房间功能角落、门口与外面的小路；全产品按 8 类基础场景规划，后续增加学校公共区、教室／活动室、工作空间、独立生活的新住处。
- 事件画面由基础场景、镜头、时间／天气、道具状态和 Morrow 动作组合，不为每个事件制作整套独立背景。
- **剧情先于教学**：所有主线、日常和记忆回访事件先定稿独立成立的剧情、Morrow 动机和用户参与理由，再由剧情确定用户真实需要说的英文，最后设计教学。禁止先定词汇或句型再反向制造剧情、世界状态或视觉变化。
- 事件制作顺序固定为：剧情与角色动机 → 用户真实表达需求 → 自然英文目标句 → 自然中文理解与 Morrow 中文行动提示 → 输出前教学拆解 → 页面、语音、交互和学习证据。
- 所有中英文都要符合各自语言的自然逻辑和 Morrow 温柔、好奇、克制而可爱的性格；中文符合中国人口语和叙事习惯，英文符合母语者情境表达，不幼儿化、不卖萌、不逐字硬译。
- 主线事件剧情与中英文未审定前，不进入教学原型、正式语音和工程冻结。
- 支持量分为启蒙支持、基础支持、自主表达三档，根据实际表现动态调整；用户可随时选择简单一点。
- 取消“和 Morrow 说话”、开放聊天和课程外自由输入；所有内容由 Morrow 按预设课程推进。
- 用户只在课程内进行触摸、选择、排序、填词、跟读、听力确认、查看中文、重听、暂停和安静陪伴。
- 明确标记为跟读的目标单词、短语和句子必须录音并由口语识别确认通过，不能点击跳过或用文字代替；判断目标是内容可被理解，不要求标准口音。
- 跟读未通过时依次提供重听、慢速、音节提示、回听和重试；允许无限重试，不使用羞辱或考试式反馈。
- 麦克风拒绝、静音、ASR 无结果、环境噪音和网络中断时允许暂停或离开，并保留“跟读待完成”；不算失败、不算学会、不结算对应学习目标。
- 人生结构固定为四阶段七章节：幼年期（第一、二章）、学龄期（第三、四章）、青年期（第五、六章）、独立期（第七章）。
- 普通章节完成使用章节结算页；只有跨人生阶段时播放约 8—15 秒的阶段揭幕短片。新阶段必须持续体现在 Morrow 外观、动作、语言能力、环境和成长页中。
- 暂停不惩罚、不丢已确认状态；返回后自然恢复。
- 成长和词语回声只展示已发生事实，不预告未来具体内容。
- 冻结房间底图与 Morrow 核心形象不重画；UI 独立叠加。

## 待体验确认后冻结

- 首次相遇每一步的最终停留时长与按钮文案。
- 首页主动邀请气泡与底部主要按钮的最终垂直位置。
- 情境回应区、帮助卡与录音控制同时出现时的空间分配。
- 跟读通过阈值、噪声容忍范围和逐级帮助触发次数的真实设备校准值。
- 章节结算页与阶段揭幕短片的最终文案、节奏和视觉表现。
- 4 个首两章基础场景的具体镜头清单、时间／天气变体和道具状态清单。
- 互动结束层保留“更自然表达”的出现阈值。
- 暂停恢复卡片的默认优先级。

## 正式工程替换边界

- 原型本地状态替换为正式状态服务，新增人生阶段、章节完成、场景组合和“跟读待完成”状态；已确认的页面可见逻辑保持一致。
- 模拟语音／ASR 替换为真实适配层；必修跟读只有识别通过才写入完成证据，设备或服务异常不得伪造通过。
- 静态 Morrow 表现替换为 Live2D／动画素材，触发语义不变。
- Web、小程序、App 只替换录音、播放、授权、缓存、登录和安全区适配，不复制业务逻辑。
