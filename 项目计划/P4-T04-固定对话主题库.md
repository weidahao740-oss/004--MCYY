# P4-T04 固定对话主题库（8—12 个）

## 1. 状态

✅ 已完成（2026-09-21）。实际交付 10 个可重复轮换的日常对话主题。

## 2. 任务目标

在主线章节事件之外，准备 8—12 个固定对话主题，作为日常轮换内容，避免连续使用时因主线事件池过小而重复同一剧情。每个主题与 Morrow 当前成长阶段的词库、句型和生活场景匹配。

## 3. 任务范围

- 按 `MORROW_LIFE_STORY_BIBLE.md` 与 `LEARNING_SCENARIO_LIBRARY.md`，为首发阶段选定 8—12 个固定对话主题。
- 每个主题定义：触发情境、Morrow 目标英语能力、用户输入方式（文字/语音）、标准路径、误解路径、恢复路径、结果、新增或更新的记忆、可复现表达。
- 每个主题至少 2—3 条有效分支，并保留"稍后继续"出口。
- 按 `FIXED_CONTENT_CONTRACT.md` 结构化录入主题配置，接入固定内容引擎。
- 所有主要英文台词配人工中文译文；标注需要预制音频的台词。
- Web 端作为日常事件或对话主题自然进入，不与主线事件抢入口。

## 4. 不包含

- 不做主线章节事件扩展（第三章及以后见阶段 6）。
- 不接真实云 ASR 或 TTS 服务（当前 mock + 预制 WAV）。
- 不迁移 PostgreSQL 或接入云端基础设施（云冻结）。
- 不做开放式生成对话或自由聊天（MVP 只走声明过的固定主题）。

## 6. 验收标准

- 8—12 个固定对话主题全部可从 Web 端进入并完成。
- 每个主题至少 2—3 条有效分支，误解可恢复。
- 所有主要英文内容有经人工检查的中文译文。
- 连续使用期间不因内容池过小而连续重复同一主题。
- 主题内容不突破 Morrow 当前成长阶段的词库与句型上限。
- `npm run typecheck` 与 web build 通过。
