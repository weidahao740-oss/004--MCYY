## 0. 统计口径说明（v2.0 新增）

### 0.1 active / receptive 定义

- **active（Morrow 自己会说）**：Morrow 主动台词中实际说出的内容词。以 `CHAPTER_01_BIRTH_CONTENT.md` 全部 76 句 Morrow 台词为统计范围，逐句提取名词/动词/形容词/关键副词/固定短语，去重并按屈折归并后计数。
- **receptive（Morrow 听得懂）**：Morrow 自己台词中出现的全部 active 词 + 用户参考句/触发短语中出现但 Morrow 台词中未出现的内容词。receptive 始终严格大于 active。

### 0.2 词量计算规则

- **计入词目**：名词、动词（屈折归并）、形容词、关键副词、固定短语/搭配。
- **不计入词目**：功能词（I/the/a/to/and/of/in/on/at/for/it/is/are/was/were/be/been/do/does/did/have/has/had/will/would/can/could/should/not/no/yes/but/or/so/if/that/this/these/those/there/here/what/when/where/why/how/who/which/me/my/your/you/we/us/our/they/them/their/as/too/also/now/then/still/yet/just/only/very/much/many/some/any/one/all/each/other/another/about/with/from/into/under/over/after/before/until/since/than/up/down/out/off/again/once/never/always/often/maybe/perhaps/really/quite/almost/nearly/either/neither/both/let's/don't/can't/won't/isnt/aren't/I'm/you're/we're/it's/I've/you've/we've/they've/I'll/you'll/we'll/they'll/I'd/you'd/we'd/they'd）。
- **专有名词**：Morrow 不计入词目。
- **去重规则**：同一词目在多个事件中重复出现只计一次。
- **屈折归并**：sound/sounds/sounding 归为 sound；say/said/saying 归为 say；leave/leaving/left 归为 leave。

### 0.3 与差异分析报告的关系

本计划 v2.0 的全部数字均来自 `第一阶段课程大纲差异分析.md` 第 3、4、5 节的逐句统计结果。差异分析子代理对 76 句 Morrow 台词逐词提取后得出：active 82 词目、receptive 额外 28 词目、最长句 18 词。本计划在此基础上构建学习链路和复现调度。

## 1. 文档说明

### 1.1 设计原则

1. **词库严格从真实台词反推**：本计划中每一个 active 词、receptive 词、搭配和句型，都必须能追溯到 `CHAPTER_01_BIRTH_CONTENT.md` 中具体事件的具体台词。
2. **active < receptive**：Morrow 自己稳定输出的词少于它能听懂用户说的词。
3. **复现嵌入自然情境**：所有学习复现都必须在 Morrow 正在生活的场景中自然发生，不弹"今日复习"、不突然考试。
4. **一次情境最多带回1条重点表达**：不为了复习强行改变 Morrow 正在做的事。
5. **动态生活状态保留**：一次打开只展示一个主要状态，同一日常状态相邻不重复。

### 1.2 语言边界（第一章章轨上限，v2.0 修正）

| 维度 | 上限 | 已出现代表 | 修正说明 |

## 9. 间隔复现调度计划

### 9.1 复现时间节点

| 阶段 | 时间间隔 | 复现方式 | 嵌入场景 |
|------|---------|---------|---------|
| 首次回采 | 首次独立成功后 2-3 个互动 | 同一词在新语义场景自然出现 | 日常轮换事件（4/6/7/8/13） |
| 第二次回采 | 首次回采成功后 5-7 个互动 | 换一个匹配场景复现 | 主线推进事件或新日常事件 |
| 低频回采 | 约两周后 | 不强制，语义匹配时自然带回 | 任意场景，一次只带1条 |

### 9.2 复现嵌入方式

**原则：复现必须嵌入自然生活情境，不变成弹题。**

具体嵌入方式：

1. **日常事件作为复现场景**：
   - E01-04（感觉事件）：可自然带回 E01-03 的 *new* 或 E01-09 的 *like*
   - E01-06（读信事件）：可自然带回 E01-02 的 *word* 或 E01-05 的 *slow*
   - E01-07（声音事件）：可自然带回 E01-02 的 *bell* 或 E01-01 的 *hear*
   - E01-08（分享事件）：可自然带回 E01-09 的 *What about you?*
   - E01-13（不确定事件）：可自然带回 E01-02 的 *I'm not sure*

2. **回访事件作为复现高点**：
   - E01-11（记住第一句）：自然引用用户之前说过的话，复现旧表达
   - 一次只引用一条记忆，不罗列

3. **主线事件中的复现**：
   - E01-05（看光）：复现 E01-01 的 *quiet*
   - E01-09（喜好）：复现 E01-04 的 *feeling*
   - E01-10（明天计划）：复现 E01-06 的 *letter*
   - E01-12（出门）：复现 E01-05 的 *window* 和 E01-10 的 *road*

### 9.3 复现调度规则

| 规则 | 说明 |
|------|------|
| 一次情境最多1条 | 任何一次互动最多自然带回1条重点表达，不堆复习 |
| 相邻不重复 | 相邻两个事件不重复同一核心表达 |
| 语义匹配优先 | 只有当前场景语义合适时才复现，没有合适语义就推迟 |
| 中性结果记录 | 用户没使用旧表达时记为中性，不催促、不降级 |
| 不弹"今日复习" | 绝不突然考试或弹出复习提示 |
| 动态状态约束 | 复现不能为了复习强行改变 Morrow 正在做的事 |

### 9.4 具体复现路线示例

以 **bell**（铃铛）为例：

| 阶段 | 事件 | 复现方式 |
|------|------|---------|
| 首次接触 | E01-02 恢复物品 | Morrow 说 *a small bell*，用户选择/触摸 |
| 识别确认 | E01-02 同事件 | 用户触摸 bell 轮廓，Morrow 说 *The bell makes one low note.* |
| 提示下使用 | E01-02 同事件 | 用户展开帮助后说 *bring back the bell* |
| 独立使用 | E01-02 同事件 | 用户自由说出 bell |
| 首次回采（2-3互动后） | E01-07 找回声音 | Morrow 说 *A small sound comes back*，用户自然辨认像 bell |
| 第二次回采（5-7互动后） | E01-11 记忆回访 | Morrow 引用用户第一次说 bell 的话 |
| 低频回采（两周后） | 任意日常事件 | 语义匹配时自然提起 |
| 跨场景迁移 | 第二章 | 铃铛声在新场景中再次出现 |

## 10. 词语回声归类规则

### 10.1 三级归类定义

| 等级 | 进入条件 | 页面展示 |
|------|---------|---------|
| **最近遇见** | 学习项真实出现在用户已经进入的情境后即可进入 | 词语回声页最近遇见区，显示刚学过的词/搭配/句型 |
| **还想再用** | 已识别或提示下使用，但尚未在新场景无提示使用；或自然回采时明显需要帮助 | 词语回声页还想再用区，提示用户可以再试试 |
| **已经很熟** | 至少在两个不同语义场景无提示正确使用，且最近一次仍能正确表达 | 词语回声页已经很熟区，显示用户已掌握的内容 |

### 10.2 升降级规则

| 变化 | 条件 |
|------|------|
| 最近遇见 → 还想再用 | 用户在新场景中尝试使用但需要提示，或自然回采时明显卡壳 |
| 还想再用 → 最近遇见 | 回退后重新 encounter（长期未复现时回退） |
| 还想再用 → 已经很熟 | 在两个不同语义场景无提示正确使用 |
| 已经很熟 → 还想再用 | 长期（两周以上）未使用后再次遇到时需要提示 |

### 10.3 展示原则

1. 页面只展示用户已经遇见的内容，未来词语不可见。
2. 不显示分数、正确率、"还差多少"。
3. 每个等级只显示用户实际经历过的内容，不凑数。
4. 词语回声是用户回看自己学过什么的地方，不是待办清单。
